## 不高兴就喝水

- 链接: [面试官自爆程序员面试技巧，技术不够，技巧来凑](https://www.bilibili.com/video/BV1j44y1r7nd/)
- 简历
	1. 简历上的一定要是你会的
	2. 技术面不需要写期望薪资
- 自我介绍
	1. 先了解对方, 然后针对对方说出自己的优势
	2. 讲擅长的技术

	1. 不会的, 用会的代替
	2. 项目相关亮点要注重

	1. 要在本地长远发展的打算
	2. 职业生涯的规划
