# Anki 问题前缀名 (如 Java 面试题)

1. 面向过程和面向对象的区别 #card

	面向对象和面向过程区别如下:
	1. 思考方式不同:
		- 面向对象思考问题从对象的角度出发,将现实世界分解成各种对象,然后考虑对象之间的通信与交互。
		- 面向过程思考问题从任务或功能的流程出发,将问题分解成一系列步骤,然后实现这些步骤。
	2. 设计方式不同:
		- 面向对象强调使用类和对象来封装数据和行为。对象与对象之间通过消息传递来进行通信与交互。
		- 面向过程强调程序的流程和步骤,使用过程或函数来实现具体功能。过程与过程之间通过参数传值进行通信。
	3. 在重用, 维护和扩展性上, 面相对象要优于面向过程
