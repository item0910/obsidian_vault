## Switch

### Switch 导出存档

- 链接: [switch导出更换存档教程，checkpoint和jksv都可以_攻略 (bilibili.com)](https://www.bilibili.com/video/BV1y54y1J7P8/)

#### 1. 安装 Checkpoint

前端需要在相册里 Aws..的软件中通过根目录的 Checkpoint.nro 文件安装, 每次升级如果出现问题都需要安装一次前端

#### 2. 删除存档

在 Switch 通过 DBI 连接时有一个 Saves 的文件夹, 直接找到存档删除

#### 3. 备份存档

通过 CheckPoint 备份, 注意需要先创建一个游戏的文件夹 (打开游戏一次)

#### 4. 还原或者使用别人的存档

找到 SD Card/Switch/checkpoint/saves 内的游戏存档文件, 放入, 并通过 CheckPoint 的 R 键导入.

### Switch 金手指

1. 看准程序 ID 和编译 ID, 分别对应着文件夹和金手指文件的 ID, 通过 L + ↓来呼出特斯拉查看
2. 将金手指放入 atmosphere -> contents 中, 呼出使用
