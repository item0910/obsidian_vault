## WeiboDL

1. **第一步、安装油猴插件“WeiboDL 异步增强版”**
油猴直接安装：https://greasyfork.org/scripts/369485
作者 Github 下载：https://github.com/yukinotech/WeiboDL
作者软件介绍：一个**微博相册**爬虫，纯 javascript 爬取，微博图片下载

2. 安装好插件，打开微博用户主页，版头上方会新增一个解析框, 点击框里的 "run"，它会自动开始爬用户相册所有图片地址，解析速度大概 1 页/秒。
	![](附件/image/步骤_下载微博相册-1708253177824.jpeg)
3. 爬完之后会弹出一个新标签页显示所有图片地址，也会提供包含所有图片地址的 txt 下载（这一步需要注意网页有没有关闭“阻止微博弹窗”）, 没有弹出的话, 按 F12 在控制台 console 里找
4. 用迅雷, IDM 等软件下载

## gallery-dl

微博上有时候遇到画师大佬，就想把他的相册整个下载下来，gallery-dl 可以很简单地实现。

gallery-dl 项目仓库：[链接](https://github.com/mikf/gallery-dl/)

### 下载工具

```
pip install gallery-dl
```

下载工具

### 下载视频和相册

```
gallery-dl https://weibo.com/u/6550815288
```

这是最简单粗暴的下载方式，下载所有的相册和视频等等。

如果只要下载相册，那么 url 要修改一下：

```
gallery-dl https://weibo.com/u/6550815288?tabtype=album
```

### 下载的同时重命名

批量重命名
下载下来的文件乱七八糟的。gallery-dl 还支持批量重命名，文档在 String Formatting。

这个文档对如何获取 metadata 数据语焉不详。看 gallery-dl -h 了解到可以通过 gallery-dl -K 获取页面能用的变量。

```
gallery-dl -K "https://weibo.com/u/6550815288"
```

在输出中的 Keywords for filenames and --filter 里找到图片的时间戳是 status[date]，多幅图的序号是 num，拓展名是 extension，然后把命令改成这样：

```
gallery-dl -d "E:" -f "{status[date]}_{num}.{extension}" "https://weibo.com/u/2558162761?tabtype=album"
```

- 默认下在 D 盘一个叫 "weibo" 的相册内
