## **主要流程总结：**

- 问题描述: 代码图书有时候中英连在一起, 很难观感
- 脚本文件夹: 电子书 _ 中英结合图书（代码书籍）文本处理（区分中英文）

1. **文件准备：** 将代码图书中的 HTML 文件文本复制过来，并准备好用于处理的脚本。
2. **初步替换：** 使用 Python 脚本进行初步替换：
    - 替换 `<code>` 和 `</code>` 标签中的内容。
    - 将 `<p>` 标签临时替换为 `'陈沛'`。
3. **在 Obsidian 中处理：** 将文件放入 Obsidian 进行 Linter 处理。
4. **恢复标签：** 最后，将 `'陈沛'` 替换回 `<p>` 标签。

## 代码图书中英分离

1. 先把 html 文件文本复制过来, 找到如何到 obsidian 中 linter 的方法
2. 找到后, 做预处理, 如下面这个, 把文件做初步替换

```python
import os

# 获取脚本所在目录
script_dir = os.path.dirname(os.path.abspath(__file__))
file_path = os.path.join(script_dir, '1.txt')

# 读取文件内容
with open(file_path, 'r', encoding='utf-8') as file:
    content = file.read()

# 替换指定内容
content = content.replace('<code>', '<code> ')
content = content.replace('</code>', ' </code>')
content = content.replace('<p>', '陈沛')

# 写回文件
with open(file_path, 'w', encoding='utf-8') as file:
    file.write(content)

print(f"文件'{file_path}'中的内容已更新。")

```

1. 然后放到 obsidian 中进行 Linter
2. 然后把 ' 陈沛 ' 换回 ''<p>''
