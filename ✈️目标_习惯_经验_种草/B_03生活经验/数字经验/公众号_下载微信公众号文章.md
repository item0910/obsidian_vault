## 下载微信公众号文章具体步骤

1. 点出微信公众号文章的链接 (这一步暂时没有好的办法, 只能手点)
2. 把链接们保存到收藏夹后, 导出, 再从导出的 html 文件中用正则替换的方式只留下链接例如: https://mp.weixin.qq.com/s/wvVD7sVnoTknd3ZEMKdyVg
3. 用加命令的 py 脚本, 添加工具命令到链接前面:

```python
with open("Links.txt", "r") as file:
    lines = file.readlines()

with open("Links.txt", "w") as file:
    for line in lines:
        file.write("wxArticleCatcher " + line)
```

1. 用多线程的方式批量下载 (暂时没有循环的办法)

```python
import subprocess
import threading

# 最大并行线程数
MAX_THREADS = 64

def execute_command(cmd):
    """执行单个命令的函数"""
    subprocess.run(cmd, shell=True)

# 读取命令
with open("Links.txt", "r") as file:
    commands = file.readlines()

threads = []

for cmd in commands:
    # 创建并启动线程
    t = threading.Thread(target=execute_command, args=(cmd.strip(),))
    t.start()
    threads.append(t)

    # 如果达到最大线程数，等待其中一个线程完成
    while len(threading.enumerate()) > MAX_THREADS:
        pass

# 等待所有线程完成
for t in threads:
    t.join()

print("All commands executed!")

```
