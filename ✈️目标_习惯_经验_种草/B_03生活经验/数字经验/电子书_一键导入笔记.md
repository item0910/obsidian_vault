1. 在 Calibre 安装 Highlights to obsidian 插件
2. 根据不同的使用场景, 设置插件的 Config

## 1. 导入普通读书笔记

- Note title format: `阅读笔记_{title}_{authors}`
- Note body format:

```js
> [!摘抄] {notes}
{blockquote}
```

- Body format for highlights without notes: 同上

```js
> [!摘抄] {notes}
{blockquote}
```

- Header format (avoid highlight-specific data like (highlight} or furl}):

```
---
title: 阅读笔记_{title}
date: {date}
categories: 
tags: 
author: {authors}
---

- 图书出版日期 (视频投稿日期): 
- 一行精华:

## 摘抄内容


```

- 最后一个选项新建笔记的话就勾选.

## 2. 导入单词学习

- Note title format: `Anki_{title}_{authors}`
- Note body format:

```

- {blockquote} #card 
	{notes} 


```

- Header format (avoid highlight-specific data like (highlight} or furl}):

```
---
cards-deck: {title}
---

## {title}


```

- 所以, 学习新单词的方式如下:
	1. 看的时候会学一遍
	2. 整理笔记的时候, 又会学一遍, 因为要找到那个不会的单词
	3. 整理 markdown 的时候, 又会学一遍
	4. 到了 Anki 中, 又会学若干遍.
