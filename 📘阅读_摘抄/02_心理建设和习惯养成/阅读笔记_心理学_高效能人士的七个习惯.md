## 高效能人士的七个习惯

1. 依赖期 -> 完成进入独立期
	1. Be proactive 积极主动
	2. begin with the end 以终为始
	3. first things first 要事第一
2. 独立期 -> 实现互相依赖
	1. think win-win 设法双赢
	2. seek first understand before to be understood 先理解再尝试被理解
	3. synergize 统筹宗效
3. sharpen the saw 不断更新
