## 怎样挖掘你的潜在能力

### 1. 认识自我

1. 什么是能力

	1. 放远目光，将自我的能力（和待激发的潜能）视作最宝贵的财富
	2. 认同自己，我很重要，我是一流
	3. 努力追求进步，哪怕进步微小。
	三个思想准备
		1. 要积极看待（be proactive）
		2. 要养成习惯（原子习惯）
		3. 从小事做起（勿以善小而不为）

总结：用积极的心态有纪律的每天小进步

1. 自我分析

	1. 相信自己的能力（你曾经有不能做的事情，但是也是做到了）
	2. 自尊；靠着装来体现你的自尊
	3. 对自我自尊的判断
		1. 苦恼和发怒：值得吗
		2. 外表：能表现我是一个自尊的人吗
		3. 语言：合适吗
		4. 读物：适合我读吗
		5. 谈话：像是取得成功的人的言谈吗
		6. 工作：怎么介绍我的工作呢

	4. 自我分析的提问（包括生理）
		1. 自己的长处是什么？最擅长做什么工作？勉强能做的工作有哪些？
		2. 自己取得最大成绩的工作是什么？体现了你的什么能力和技术？
		3. 哪些工作失败了？原因是什么？
		4. 自己遭遇了哪些困难？其中最大的困难是什么？

	5. 自我工作的分析

		1. 我的使命是什么？
		2. 我的工作有什么意义？
		3. 我具备什么才能？
		4. 最适合我的工作是什么？
		5. 我在做哪些有价值的工作？哪些没有价值的工作？

	6. 有时候缺点换一个方向看也能成为优点 P16
	7. 举出自己的五条优点（请教熟悉你的人）然后在优点后面填上你认为没有这个优点的伟人。
	8. 如何改正缺点：
		1. 不可将改正缺点的计划铺的过大，可以优先解决主要的缺点
		2. 用小的进步去推进
		3. 有效的利用外部条件：读书会，别人的建议等
		4. 制定计划、列表，养成习惯
		5. 定期革新计划，检查效果

### 2. 改善自我

1. 目标和计划

	1. 想象力：“我在修建大教堂”
		辩解症：“我为什么不做”

	2. 规划之前
	看清领域，对自己的各个方面进行补足

	3. 制定目标
	长期规划和短期规划
	制定好长期规划后，短期规划对其进行服务

	4. 实现目标的四个步骤
		1. 把目标清楚的记在心里，目标视觉化
			用一本本子将自己的目标画下来，并以正在实现目标的心来看待他们
		2. 核实目标（用语言叙述出来）
		3. 驱散消极思想
		4. 实干

	5. 理想破灭的五个炸弹

		1. 自我轻视
		2. 保险症
		3. 竞争
		4. 家长之命和其他责任

2. 如何安排工作

	1. 准备工作日志并安排顺序
	2. 立刻着手
	3. 目标、阻力、计划和步进

3. 如何运用时间

	1. 衡量时间的方法（算每分钟）
	2. 记录时间

4. 如何调节心理

	1. 深入研究 产生兴趣
	2. 传递好消息
	3. 可以换换脑子，散散步
	4. 洗掉一天的污垢（仪式）
	5. 激发创造力：
		1. 排除不可能
		2. 阅读娱乐旅行
		3. 交际

### 3. 不怕挫折，勇于寻求帮助

## 怎样挖掘你的潜在能力 思考/重点经验

1. 自尊和自我认同
2. 计划和行动
3. 积极和寻求帮助
	- 人的心中总是有一滩巨大的洪水猛兽，随时可以将你带崩，一定要通过计划、积极的心态和他人的帮助来不断战胜。这就需要在社会中独立
