## 如何高效学习 (整体学习)

### 1. 整体学习的框架

1. 框架
2. 模型
3. 高速公路

### 2. 整体学习的步骤

1. 获取
2. 理解
3. 拓展
	1. 背景拓展: 历史
	2. 横向拓展: 联系
	3. 纵向拓展: 联想
4. 纠错
5. 运用
	1. 以在周期内完成小项目为导向

### 3. 信息的种类

1. 随意信息: 没规律的
2. 观点信息: 对或错的: 广泛最重要
3. 过程信息: 有步骤的
4. 具体信息: 可视化的
5. 抽象信息: 数学化的

### 4. 小方法

1. 能量管理: 精力管理有很多书: 作者推荐:《精力管理：管理精力，而非时间，是高效、健康与快乐的基础》（The Power of Full Engagement）
	1. 增加: 运动
	2. 管理: 睡眠 食物 适当休息
2. 周期目标完成 (集中完成)
3. 整理, 组织
4. 联想记忆

## 学习之道

### 1. 打开自我学习的大门

1. 自学能获取自己需要的知识
2. 提防智力狙击手: 恶意的贬低,古怪的试题
3. 珍惜好老师的价值

### 2. 学习的心态

1. 在专注模式和发散模式中切换: 跳出问题,从宏观角度观察
2. 休息和玩
3. 自我欣赏: 原谅自己的不足
4. 避免自负: 寻求团队合作互相补足.synergize

### 3. 知识和技能的构造以及记忆的塑造方法

1. 组块构建
	1. 将知识分成一些组块,并将注意力集中
	2. 理解每个组块 (位置和形状) 通过练习
	3. 获取背景信息 (如何利用他们)
	4. 散步和回想 (整理和复习)
	5. 穿插学习,解决混杂交错的各种问题,不要在一个问题上过度学习
2. 利用组块解决问题
	1. 下一步提示
	2. 重做一次 ,注意关键步骤
	3. 给自己添新题目或做测试
	4. 主动重复
	5. 睡眠和休息
3. 记忆
	1. 视觉记忆 (构造画面)
	2. 记忆宫殿构造
	3. 构思一个故事
	4. 打造生动形象的比喻和画面
	5. 体育锻炼能增强记忆
4. 数学的诗意
	1. 简化概念,并对其拟人化 (爱因斯坦对于光子的想象: 如果我是光子,我如何观察自己)
	2. 实体类比

### 4. 战胜拖延

1. 有关拖延的事实

	1. 拖延的就是我们恐惧的事务,不擅长的事务
	2. 大脑倾向于获得暂时性的良好
	3. 拖延会成瘾

2. 对抗拖延的四个方面

	1. 信号: 发觉拖延的信号
	2. 反应程序: 制定计划: 番茄工作法
	3. 奖励机制: 不拖延就奖励: 看电影,吃小吃
	4. 信念: 把自己的状态和需要达到的状态做对比（榜样对比）

3. 战胜拖延的小技巧和方法

	1. 让目标触目可及 (在书上标出要完成的位置等)
	2. 番茄工作法: 关注过程
	3. 立刻行动: 两分钟法则
	4. 隔绝干扰

### 5. 学习小技巧

1. 冥想和正面思维
2. 写任务清单 (可执行的),然后不要再不断添加
3. 参加考试
4. 回想和抽卡测试
5. 用不同的技巧解决
6. 困难的先做

### 6. 学习之道的思考

1. 拖延实际上是恐惧的化生,当你避无可避或者勇敢非凡时,就不存在拖延了. 用长期思维来思考各类人生问题, 也能对拖延的利弊有较清楚的认识.
2. 适当的考试确实有助于帮助学习技能和知识.
3. 关注过程,不要关注结果. 还是那句话,一晚上抄不完暑假作业.
4. 对知识要对其抽象,并加以回想.通过构建知识的拼图或宫殿来增进整体的理解. 知识仿佛就是待盖的高楼, 首先,要打地基和砖,然后,要有人盖,其次,要有图纸,最后,要装修.

## 学习一项知识或技能的方法

### 1. 如何学习

1. 决定你的目标和程度
2. 解构知识或技能
3. 调查与调整,3-5 个信息源
4. 训练
	1. 去除干扰,找到专注的状态并培养训练
	2. 以完成任务为计划,大约持续 20 个小时即可

### 2. 如何复习

1. 间隔: 第一次学习后隔一天复习,然后每隔 3-5 天复习一次,一共复习 5 次
2. 通过教别人来复习: 解构出易懂的概念 - 通过比喻的方式: 费曼

### 3. 其它小技巧

1. 承认变好
2. 习惯记录 (番茄工作法)
3. 开始取舍
4. 从小事做起 (2min)
5. 拥抱风险和失败
