### 访问方式

1. 动态库的方式, 链接在程序内部作为方法调用: 比如 java 的 import
2. 网络访问: socket server 方式: 需要协议和考虑网络状况
为了可用性采用第二种方式

### 问题 1. 与 Redis 相比, SimpleKV 有什么缺憾

![[附件/image/01_基本架构：一个键值数据库KV__1.jpg]]

从应用维度和系统维度来看这个问题.

应用:

- 可存数据应用
- 淘汰机制
- 集群
系统维度:
- 高性能:
	- 索引: 范围操作
	- 不同的数据采用不同的数据结构
	- 内存分配器不同
- 高可靠
	- 有 RDB 和 AOF 作为持久化手段
	- 有主从和哨兵机制作为结构支撑
- 高可拓展
	- Redis 可以切片集群
- 其它:
	- 运维调试工具
