# 344 反转字符串

```java
class Solution {
    public void reverseString(char[] s) {
        int limit = s.length / 2;
        for(int i = 0; i < limit; i++){
            swap(i, s.length - 1 - i, s);
        }
    }

    public void swap(int a, int b, char[] s){
        char t = s[a];
        s[a] = s[b];
        s[b] = t;
    }
}
```
