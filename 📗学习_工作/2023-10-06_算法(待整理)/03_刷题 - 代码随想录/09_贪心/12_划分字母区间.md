# 763.划分字母区间

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] hash = new int[26];
        char[] chars = s.toCharArray();
        for(int i = 0; i < chars.length; i++){
            hash[chars[i] - 'a'] = i;
        }
        List<Integer> res = new ArrayList<>();
        int last = -1;
        int index = 0;
        for(int i = 0; i < chars.length; i++){
			//始终保持需要的是最远的那个边界
            index = Math.max(index, hash[chars[i] - 'a']);
            if(i == index){
				//这里是根据题目于要求插入结果和更新边界
                res.add(i - last);
                last = i;
            }
        }
        return res;
    }
}
```
