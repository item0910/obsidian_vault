# 376.摆动序列

```java
class Solution {
    int max = Integer.MIN_VALUE;
    public int wiggleMaxLength(int[] nums) {
        int curDiff = 0;
        int preDiff = 0;
        int count = 1;
        for(int i = 1; i < nums.length; i++){
            curDiff = nums[i] - nums[i - 1];
            if((curDiff > 0 && preDiff <= 0) || (curDiff < 0 && preDiff >= 0)){
                count++;
                preDiff = curDiff;
            }
        }
        return count;
    }
}
```
