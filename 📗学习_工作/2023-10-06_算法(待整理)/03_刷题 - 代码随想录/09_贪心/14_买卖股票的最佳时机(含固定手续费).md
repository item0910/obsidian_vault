# 714. 买卖股票的最佳时机 (含手续费)

```java
class Solution {
    public int maxProfit(int[] prices, int fee) {
        int res = 0;
        int minPrice = prices[0];
        for(int p : prices){
            //假设买入了, 买入价是这个minPrice
            minPrice = Math.min(minPrice, p);
            if(p >= minPrice && p <= minPrice + fee){
                //不划算, 跳过
                continue;
            }
            if(p > minPrice + fee){
                res += p - minPrice - fee;
                //仍然是假设在这里持有的思维.假设我没卖,我的成本价应该是什么
                minPrice = p - fee;
            }
        }
        return res;
    }
}
```
