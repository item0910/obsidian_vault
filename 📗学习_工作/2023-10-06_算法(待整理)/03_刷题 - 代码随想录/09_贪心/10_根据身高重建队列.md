# 406. 根据身高重建队列

```java
class Solution {
    public int[][] reconstructQueue(int[][] people) {
        Arrays.sort(people, (a, b) ->{
            //如果两个身高相同, k小的排前面
            if(a[0] == b[0]){
                return a[1] - b[1];
            }
            //整体是身高高的排前面
            return b[0] - a[0];
        });

        LinkedList<int[]> list = new LinkedList<>();
        for(int[] p : people){
            //将元素p插入下标为p[1]处
            list.add(p[1], p);
        }
		//注意是二维数组
        return list.toArray(new int[people.length][]);
    }
}
```
