# 122. 买卖股票的最佳时机

```java
class Solution {
	//关键是找到profit对列, 只取正的.
    public int maxProfit(int[] prices) {
        int[] profit = new int[prices.length - 1];
        for(int i = 0; i < profit.length; i++){
            profit[i] = prices[i + 1] - prices[i];
        }
        int result = 0;
        for(int i = 0; i < profit.length; i++){
            if(profit[i] > 0){
                result += profit[i];
            }
        }
        return result;
    }
}
```
