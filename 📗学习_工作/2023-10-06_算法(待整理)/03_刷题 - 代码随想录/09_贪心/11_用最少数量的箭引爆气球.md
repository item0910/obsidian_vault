# 452.用最少数量的箭引爆气球

```java
class Solution {
    public int findMinArrowShots(int[][] points) {
        if(points.length == 0){
            return 0;
        }
        Arrays.sort(points, (a, b) ->{
            return Integer.compare(a[0], b[0]);
        });
        int count = 1;
        for(int i = 1; i < points.length; i++){
            
            if(points[i - 1][1] < points[i][0]){
                //不挨着
                count++;
            }else{
                //挨着, 更新右边界
                points[i][1] = Math.min(points[i - 1][1], points[i][1]);
            }
        }
        return count;
    }
}
```
