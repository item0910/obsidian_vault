# 98. 验证二叉搜索树

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isValidBST(TreeNode root) {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    public boolean isValid(TreeNode root, long lower, long larger){
        if(root == null){
            return true;
        }
        if(root.val <= lower || root.val >= larger){
            return false;
        }
        return isValid(root.left, lower, root.val) && isValid(root.right, root.val, larger);
    }
}
```

按照中序遍历, 搜索二叉树应该按照单调排列.

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isValidBST(TreeNode root) {
        Stack<TreeNode> stack = new Stack<>();
        mid(root, stack);
        int size = stack.size();
        int pre = stack.pop().val;
        for(int i = 1; i < size; i++){
            int last = stack.pop().val;
            if(pre <= last){
                return false;
            }
            pre = last;
        }
        return true;
    }

    public void mid(TreeNode root, Stack<TreeNode> stack){
        if(root == null){
            return;
        }
        mid(root.left, stack);
        stack.push(root);
        mid(root.right, stack);
    }
}
```
