# 96.不同的搜索二叉树

```java
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for(int i = 2; i <= n; i++){
            for(int j = 0; j < i; j++){
                int left = j;
                int right = i - j - 1;
                dp[i] += dp[left] * dp[right];
            }
        }
        return dp[n];
    }
}
```
