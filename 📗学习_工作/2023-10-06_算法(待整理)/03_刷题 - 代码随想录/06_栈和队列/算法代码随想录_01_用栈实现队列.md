# 232.用栈实现队列

- 思路:
1. 准备两个栈 left 和 right
2. push():
	1. 直接 push 进左栈
3. pop():
	1. 看一下右栈是不是为空, 如果为空, 那么把左栈的所有元素都倒进右栈
	2. 弹出右栈的顶端
	3. 注意点: 左右栈都为空时, 需要 throw 一个 RuntimeException.
4. peek():
	1. 与 pop() 类似.

```java
class MyQueue {
    Stack<Integer> left;
    Stack<Integer> right;

    public MyQueue() {
        left = new Stack();
        right = new Stack();
    }
    
    public void push(int x) {
        left.push(x);
    }
    
    public int pop() {
        if(right.isEmpty()){
            while(!left.isEmpty()){
                right.push(left.pop());
            }
        }
        return right.pop();
    }
    
    public int peek() {
        if(right.isEmpty()){
            while(!left.isEmpty()){
                right.push(left.pop());
            }
        }
        return right.peek();
    }
    
    public boolean empty() {
        return left.isEmpty() && right.isEmpty();
    }
}
```
