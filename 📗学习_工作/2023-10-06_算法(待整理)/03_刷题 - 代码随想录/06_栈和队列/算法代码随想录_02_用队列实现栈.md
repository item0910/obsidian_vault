# 225.用队列实现栈

- 思路
1. 准备两个队列, q1, q2;
2. push 直接 push 进 q1;
3. pop()
	1. 把 q1 依次放入 q2, 剩一个返回用
	2. 把 q1 和 q2 的关系互换
4. peek()
	1. 与 pop() 类似, 注意, 需要把最后一个元素继续倒入 q2 中.

```java
class MyStack {
    Queue<Integer> q1;
    Queue<Integer> q2;

    public MyStack() {
        q1 = new LinkedList<>();
        q2 = new LinkedList<>();
    }
    
    public void push(int x) {
        q1.offer(x);
    }
    
    public int pop() {
        while(q1.size() > 1){
            q2.offer(q1.poll());
        }
        int value = q1.poll();
        Queue<Integer> temp = q1;
        q1 = q2;
        q2 = temp;
        return value;
    }
    
    public int top() {
        while(q1.size() > 1){
            q2.offer(q1.poll());
        }
        int value = q1.poll();
        q2.offer(value);
        Queue<Integer> temp = q1;
        q1 = q2;
        q2 = temp;
        return value;
    }
    
    public boolean empty() {
        return q1.isEmpty() && q2.isEmpty();
    }
}
```
