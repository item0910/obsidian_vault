# 20.有效的括号

```java
class Solution {
    public static boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();
        char[] arr = s.toCharArray();
        int n = s.length();
        for(int i = 0; i < n; i++){
            if(arr[i] == '(' || arr[i] == '[' || arr[i] == '{'){
                stack.push(arr[i]);
            }else{
                if(stack.isEmpty()){
                    return false;
                }
				//小括号的ascii码是相差1, 中括号和大括号的ascii码是相差2
                if(stack.peek() == arr[i] - 1 || stack.peek() == arr[i] - 2) {
                    stack.pop();
                }else{
                    return false;
                }
            }
        }
        return stack.isEmpty();
    }
}
```

```java
//map方法, 无需知道ASCII码
class Solution {
    public static boolean isValid(String s) {
        HashMap<Character, Character> map = new HashMap<>();
        map.put(')','(');
        map.put('}','{');
        map.put(']','[');
        Stack<Character> stack = new Stack<>();
        for(int i = 0; i < s.length(); i++){
            char c = s.charAt(i);
            if(map.containsKey(c)){
                if(stack.isEmpty() || stack.peek() != map.get(c)){
                    return false;
                }
                stack.pop();
            }else{
                stack.push(c);
            }
        }
        return stack.isEmpty();
    }
}
```
