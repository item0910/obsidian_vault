[10. 正则表达式匹配](https://leetcode.cn/problems/regular-expression-matching) #card
**动态规划** **字符串**
1. dp 设为 `dp[m + 1][n + 1]`, `dp[0][0]` 设为 true: 注意, 这里的下标和具体的字符串下标并不对应.
2. s 为 0 的时候, 如果 p 最后是 `*`, 可以往前递推 (去掉最后两位)
3. 一般情况:
   1. 当最后一个字母可以匹配时, 或者 p 最后一个是 `.` 时
   2. 当 p 最后一个是 ` * ` 时 , 且倒数第二个字母与 s 相同时, 分三种情况讨论
      1. 匹配掉 s 一个字母
      2. 匹配掉 s 若干个字母 (就是 s 减, p 不减)
      3. 一个都不匹配掉
   3. 当 p 最后一个是 `*`, 但前一个与 s 不相同, 不能匹配, 只能零匹配
   4. 其他情况, 仍然保持 false
4. `return dp[m][n]`;

[300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence) #card
**动态规划**
1. 动态规划
	1. dp[n], dp[0] = 1;int max = 1; 表示以 i 结尾的点的最长递增子序列
	2. i 从 1 开始; j 从 0 到 i, dp[i] 初始值设为 1
		1. 如果 `nums[i] > nums[j]`: 表示可以, dp[i] = Max(dp[j] + 1)
	3. 再次遍历数组, 找到最大值
2. 二分
	1. d 序列, d[n + 1], 用来穿插找到这个最大值, `d[1] = nums[0](0位置留给后面)`
	2. len = 1, i 从 1 开始,
		1. 如果 nums[i] > d[len], d[++len] = nums[i]
		2. 如果不是, 那么就要找地方插进去
			1. L = 1, R = len; pos = 0;
			2. while(L <= R ), 找到 mid
				1. 如果 d[mid] < nums[i], pos = mid, L = mid + 1; 继续找找有没有更合适的位置
				2. 反之, R= mid - 1;
			3. 最后在 pos + 1 的位置插入 nums[i]; (如果没改变就是直接改变 d[1])
	3. return len
