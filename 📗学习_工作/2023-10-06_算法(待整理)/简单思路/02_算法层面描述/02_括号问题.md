[301. 删除无效的括号](https://leetcode.cn/problems/remove-invalid-parentheses) #card
**括号问题** **回溯**
1. 计算要删除的数量:
	1. 如果是 '(', left++
	2. 否则如果是 ')', 如果 left > 0, left--; 否则, right++. left 和 right 就是要删除的括号数量
2. 回溯过程 retrace(s, 0, left, right)
	1. 如果 left = 0, right = 0, 判断是不是 valid
	2. i 从 start 开始
		1. 如果 i != start, 并且 i - 1 和 i 一样, continue
		2. left + right > len - i, return
		3. left > 0 retrace(s.substring(0, i) + s.substring(i+1), i, left - 1, right) : 注意这里新 s 长度和下标的关系
		4. right 同理
3. 判断 isValid
	1. int cnt = 0
	2. if(左括号), cnt++; else if(右括号), cnt--, if(cnt < 0): false
	3. return cnt == 0;
