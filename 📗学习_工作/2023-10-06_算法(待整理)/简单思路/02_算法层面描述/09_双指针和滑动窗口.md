[15. 三数之和](https://leetcode.cn/problems/3sum) #card
**数组排序和查找** **双指针和滑动窗口**
1. 如不够三数, 返回
2. 整理数组
3. 从左往右,
   1. 如果 nums[i] > 0, return 结果; i>=1 时, 如果 nums[i] == num[i - 1], continue
   2. L = i + 1, R = n - 1; L < R 时, sum 算出来, 如果
      1. sum == 0, 加到 res 里, Arrays.asList(三个数)
      2. 然后移动 L, 移动 R,条件 L+1 < R, R - 1 > L
      3. 再默认移动一下 L, R(两个一定是同步移动, 否则不可能成立)
      4. 然后再根据 sum 的大小情况, 移动 L 和 R
- 总结, 一共要移动三次 L, R

[42. 接雨水](https://leetcode.cn/problems/trapping-rain-water) #card
 **单调栈** **双指针和滑动窗口**
1. 单调栈
	1. 核心, 找到两边比自己大的
	2. 栈不为空 且 如果要进去的那个柱子大于栈顶, 那么弹出
		1. 记录弹出为 top, 如果此时栈空, 说明没有下面没有比他高的, 无法盛水, break
		2. left = stack.peek(), 记录左边的柱子;
		3. 计算能盛宽度, 能乘的单位是多少, 高度 : Math.min(左, 右) - height[i], 宽度: i - left - 1; 累加之
	3. stack.push(i);
2. 左右最高数组法:
	1. 每个位置能接的水取决于左右比自己高的数组最低的位置
	2. 准备两个数组 left[], right[], 分别表示比自己高的左右数组
		1. 两个数组都可以用 left[i -1], 和 right[i + 1], 推导得出
		2. 最后统一计算即可
3. 双指针 O(1) 法, leftMax, height[left], rightMax, height[right] 四个变量唱歌

[239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum) #card
**双指针和滑动窗口** **单调栈**
1. 准备 res 和栈, index 用来表示 res 的下标
2. 栈来维护最大值, 等于时候可弹可不弹
	1. 如果栈顶元素为 i - k(比如窗口是 3, i = 3 时, 实际窗口长度已经为 4 了) 时, 弹出栈顶
