[139. 单词拆分](https://leetcode.cn/problems/word-break) #card
**暴力递归** **动态规划** **字符串** **哈希表**
1. 暴力递归
	1. 把 Dict 变成 set
	2. process(0, s, set)
		1. 如果 index == s.length(): true
		2. i 从 index + 1 开始,
			1. 如果 set 有 substring(index, i), flag = process(i, s, set)
				1. 如果 flag = true, 那么就 return true
				2. 否则 continue
2. 改动态规划
	1. dp[n +1], dp[n] = true;
	2. i = n - 1 时, i-- : (把 index 看作 j, i 从后往前进行推算)
		1. j = i + 1, j <= s.length(); j++: 如果 dp[j] && wordDict.contains(s.substring(i, j)) : dp[i] = true;
	3. return dp[0];

[39. 组合总和](https://leetcode.cn/problems/combination-sum) #card
**暴力递归** **回溯**
1. 整理数组
2. 回溯过程: 0, candidates, target, 0
	1. sum = target : res.add(path)
	2. 从 index 开始, 条件 i < length && sum + candidates[i] <= target
		1. sum += can[i]; path.add(can[i])
		2. process(i, candidates, target, sum)
		3. sum -= can[i], path.remove
