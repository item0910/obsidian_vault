[287. 寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number) #card
**数组排序和查找** **链表 - 快慢指针** **二分**
- 数数法, 遍历, 用 cnt 来数出小于等于 mid 的个数
	1. L = 1, R= n - 1;
	2. while(L<= R), 先算 mid
	3. 如果 cnt <= mid, 说明正常, 不在左边, L 右移
	4. 如果 cnt > mid, OK, 有可能找到了, 先把 mid 定为 res, R 左移.
- 快慢指针法
	1. slow 和 fast 都从 0 出发
	2. do{快慢指针} while(slow != fast);
	3. slow 回 0, slow 和 fast 都一步一步走
	4. slow = fast 时, 返回 slow

[300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence) #card
**动态规划** **二分** **数组排序和查找**
1. 动态规划
	1. dp[n], dp[0] = 1;int max = 1; 表示以 i 结尾的点的最长递增子序列
	2. i 从 1 开始; j 从 0 到 i, dp[i] 初始值设为 1
		1. 如果 `nums[i] > nums[j]`: 表示可以, dp[i] = Max(dp[j] + 1)
	3. 再次遍历数组, 找到最大值
2. 二分
	1. d 序列, d[n + 1], 用来穿插找到这个最大值, `d[1] = nums[0](0位置留给后面)`
	2. len = 1, i 从 1 开始,
		1. 如果 nums[i] > d[len], d[++len] = nums[i]
		2. 如果不是, 那么就要找地方插进去
			1. L = 1, R = len; pos = 0;
			2. while(L <= R ), 找到 mid
				1. 如果 d[mid] < nums[i], pos = mid, L = mid + 1; 继续找找有没有更合适的位置
				2. 反之, R= mid - 1;
			3. 最后在 pos + 1 的位置插入 nums[i]; (如果没改变就是直接改变 d[1])
	3. return len

[215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array) #card
**二分** **数组排序和查找**
1. 在 0~n - 1 中找到 n - k 那个位置的元素 (partitionSelect)
2. partitionSelect
	1. int q = randomPartition(L, R, nums), 如果 q 是的, 那么返回 nums[q]
	2. 如果 q 小了, 那么 partitionSelect(nums, q + 1, R, k), 否则 (L, q - 1)
3. partion 和 randomPartition
	1. randomPartition
		1. 就是先选一个 random 数与 R 位置的数交换后 partition: random = r.nextInt(R - L + 1) + L;
	2. partition
		1. 以 nums[R] 为标准做 partition, 最后还要将 L + 1 位置的与 R 上的数字交换, 返回 L + 1, 就是整个 <= nums[R] 的下标
