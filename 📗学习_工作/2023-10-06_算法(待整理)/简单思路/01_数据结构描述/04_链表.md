**链表**表**

	1. class DLinkNode : 双端链表, 有 key 和值

	3. size
	4. capacity
	5. head
	6. tail
	7. 新建方法: 给一个容量
		1. size = 0, capacity 赋值
		2. head.next = tail, tail.next = head;
2. 外部方法:
	1. get
		1. cache 里如有这个 key, 返回这个 node 的值, 并且 moveToHead 它
		2. 否则返回 -1;
	2. put(key, value)
		1. 如果有, 那么 moveTohead, node 的值更新, 并放入 cache 中
		2. 如果没有, 那么 size++, 新建这个 node, addToHead, 存进 cache 中, 如果 size > capacity, 那么 Node removeNode = removeTail(), cache 里把这个 removeNode 删除
3. 内部方法
	1. void addTohead(node)
		1. node.next 指向头节点的 next, pre 指向头;
		2. 头的 next 的 pre 指向这个 node, 头的 next 指向这个点
	2. void moveToHead(mode)
		1. removeNode(node);
		2. addToHead(node);
	3. void removeNode(node)
		1. node.next.pre = node.pre
		2. node.pre.next = node.next;
	4. DLinkedNode removeTail()
		1. tail.pre 保存 tailNode
		2. removeNode(tailNode);
		3. 返回这个 tailNode

[141. 环形链表](https://leetcode.cn/problems/linked-list-cycle) #card
**链表 - 快慢指针**
1. 注意快慢指针的移动方式, 这里的目标是找到 slow == fast, 所以最初要设定他们不同的位置.

```java
	ListNode slow = head;
	ListNode fast = head.next;
	while(slow != fast){
		if(fast == null || fast.next == null || fast.next.next == null){
			return false;
		}
		slow = slow.next;
		fast = fast.next.next;
	}
	return true;
```

[142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii) #card
**链表 - 快慢指针**
1. 继续注意指针移动方式, 这里规定要从同一个地方出发, 所以把他们设定为 fast != null, 并给与退出机制
- 总结快慢指针的方式: 先确定起点, 然后设置目标, 最后确定退出机制.

```java
	ListNode slow = head;
	ListNode fast = head;
	while(fast != null){
		if(fast.next == null || fast.next.next == null){
			return null;
		}else{
			slow = slow.next;
			fast = fast.next.next;
			if(slow == fast){
				break;
			}
		}
	}
	slow = head;
	while(slow != fast){
		slow = slow.next;
		fast = fast.next;
	}
	return slow;
```

[206. 反转链表](https://leetcode.cn/problems/reverse-linked-list) #card
**链表**

```java
	ListNode pre = null;
	ListNode next = null;
	ListNode cur = head;
	while(cur != null){
		next = cur.next;
		cur.next = pre;
		pre = cur;
		cur = next;
	}
	return pre;
```
