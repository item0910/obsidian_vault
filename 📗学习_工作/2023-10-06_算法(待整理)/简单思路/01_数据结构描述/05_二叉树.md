[208. 实现 Trie (前缀树)](https://leetcode.cn/problems/implement-trie-prefix-tree) #card

1. Trie 核心结构

		1. pass
		2. end
		3. Node[] nexts
		4. new Node(){pass = 0, end = 0, nexts = new Node[26]}

	3. new Trie(){head = new Node()}
2. 核心方法:
	1. insert(String word)
		1. 先 search, 如果有, 就 return
		2. 没有: cur 指向 head
			1. 对每一个 char c: 计算 int path, 然后如果 nexts[path] 为空, 就新建出来, 然后 cur.pass++, cur = cur.next[path]
		3. 最后 cur.end++;
	2. search
		1. 对每一个字母 c 提取 path, 如果为空返回 false
		2. 最后返回 cur.end == 1
	3. startWith
		1. 对每一个字母 c 提取 path, 如果为空返回 false
		2. 最后返回 true
