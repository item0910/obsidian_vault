# 算法专项练习: 图

[207. 课程表](https://leetcode.cn/problems/course-schedule) #card
**图** **哈希表**
1. 准备 2 个结构:
	1. 课程 Map<编号, List<编号>>: 课程号和完成后可以完成的课程
	2. inDegree[], 每个课程的入度 (需要提前完成的课的数量)
2. 把入度为 0 课程号的放入 Queue 中
3. 处理 queue:
	1. visit = 0;
	2. q 不为空时
		1. 弹出 int from = q.poll()
		2. visit++; 如果 map 中有这个, 那么就把这个课程找出来, 对应所有可以完成的课程的入度 --; 如果这个入度 == 0, 那么将他也放入 queue 中

[399. 除法求值](https://leetcode.cn/problems/evaluate-division) #card
**图** **动态规划**
1. 准备几个结构:
	1. valueMap<String, Integer>, 将每一个出现的字符对应一个 value++ 存入 map 中
	2. `graph[][]` 用来记录已知的值, 先全部填好 -1
		1. 对每一个等式, va = 等式 [0], vb = 等式 [1], 存入 graph 中
	3. 从 k = 0 到 n, 如果 graph 中有 i ->k 的值并且有 k -> j 的值, 那么这个值就有两个值相乘获得
2. 查询 :
	1. 对每一个 query, 如果被除数和除数都存在, 那么找出这个坐标对应的值即可
