		1. 如果 index == s.length(): true
		2. i 从 index + 1 开始,
			1. 如果 set 有 substring(index, i), flag = process(i, s, set)
				1. 如果 flag = true, 那么就 return true
				2. 否则 continue

	1. dp[n +1], dp[n] = true;

	3. return dp[0];

[10. 正则表达式匹配](https://leetcode.cn/problems/regular-expression-matching) #card
**动态规划** **字符串**
1. dp 设为 `dp[m + 1][n + 1]`, `dp[0][0]` 设为 true: 注意, 这里的下标和具体的字符串下标并不对应.
2. s 为 0 的时候, 如果 p 最后是 `*`, 可以往前递推 (去掉最后两位)
3. 一般情况:
   1. 当最后一个字母可以匹配时, 或者 p 最后一个是 `.` 时
   2. 当 p 最后一个是 ` * ` 时 , 且倒数第二个字母与 s 相同时, 分三种情况讨论
      1. 匹配掉 s 一个字母
      2. 匹配掉 s 若干个字母 (就是 s 减, p 不减)
      3. 一个都不匹配掉
   3. 当 p 最后一个是 `*`, 但前一个与 s 不相同, 不能匹配, 只能零匹配
   4. 其他情况, 仍然保持 false
4. `return dp[m][n]`;
