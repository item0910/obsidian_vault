[287. 寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number) #card
**数组排序和查找** **链表 - 快慢指针**
- 数数法, 遍历, 用 cnt 来数出小于等于 mid 的个数
	1. L = 1, R= n - 1;
	2. while(L<= R), 先算 mid
	3. 如果 cnt <= mid, 说明正常, 不在左边, L 右移
	4. 如果 cnt > mid, OK, 有可能找到了, 先把 mid 定为 res, R 左移.
- 快慢指针法
	1. slow 和 fast 都从 0 出发
	2. do{快慢指针} while(slow != fast);
	3. slow 回 0, slow 和 fast 都一步一步走
	4. slow = fast 时, 返回 slow

[300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence) #card
**动态规划** **数组排序和查找**
1. 动态规划
	1. dp[n], dp[0] = 1;int max = 1; 表示以 i 结尾的点的最长递增子序列
	2. i 从 1 开始; j 从 0 到 i, dp[i] 初始值设为 1
		1. 如果 `nums[i] > nums[j]`: 表示可以, dp[i] = Max(dp[j] + 1)
	3. 再次遍历数组, 找到最大值
2. 二分
	1. d 序列, d[n + 1], 用来穿插找到这个最大值, `d[1] = nums[0](0位置留给后面)`
	2. len = 1, i 从 1 开始,
		1. 如果 nums[i] > d[len], d[++len] = nums[i]
		2. 如果不是, 那么就要找地方插进去
			1. L = 1, R = len; pos = 0;
			2. while(L <= R ), 找到 mid
				1. 如果 d[mid] < nums[i], pos = mid, L = mid + 1; 继续找找有没有更合适的位置
				2. 反之, R= mid - 1;
			3. 最后在 pos + 1 的位置插入 nums[i]; (如果没改变就是直接改变 d[1])
	3. return len

[15. 三数之和](https://leetcode.cn/problems/3sum) #card
**数组排序和查找** **双指针和滑动窗口**
1. 如不够三数, 返回
2. 整理数组
3. 从左往右,
   1. 如果 nums[i] > 0, return 结果; i>=1 时, 如果 nums[i] == num[i - 1], continue
   2. L = i + 1, R = n - 1; L < R 时, sum 算出来, 如果
      1. sum == 0, 加到 res 里, Arrays.asList(三个数)
      2. 然后移动 L, 移动 R,条件 L+1 < R, R - 1 > L
      3. 再默认移动一下 L, R(两个一定是同步移动, 否则不可能成立)
      4. 然后再根据 sum 的大小情况, 移动 L 和 R
- 总结, 一共要移动三次 L, R
