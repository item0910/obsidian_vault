1. long pre = Long.MIN_VALUE
2. 验证过程
	1. root == null true
	2. 左边是吗? 不是返回 false
	3. if(pre >= root.val): false(为了让只有一个 Integer.MIN_VALUE 值的二叉树成立, 所以将 pre 设置的更小)
	4. pre = root.val;
	5. return 右边是不是搜索二叉树

1. int multi = 0, 作为乘数; StringBuilder res 作为累加字符的工具

	1. 如果是数字, 那么 multi = 10 * multi +integer.parseInt(c + "");

		1. multi 入栈, res 入栈
