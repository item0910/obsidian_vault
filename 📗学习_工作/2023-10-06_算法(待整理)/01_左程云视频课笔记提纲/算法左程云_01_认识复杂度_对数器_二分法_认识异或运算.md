# 1. 算法的优劣评估

## 复杂度介绍

1. 时间复杂度 (最重要)
	排名从好到差 : O(1) < O(logN) < O(N) < O(N * logN) < O(N ^ 2) < O(N ^ 3) < .. < O(2 ^ N) < O(N!)
2. 空间复杂度 (额外)
3. 常数项 (细节): 重在实验结果

- 最优解:

> 时间复杂度 > 空间复杂度 > 常数

## 选择排序 **排序算法**

1. 思路:
	1. 默认第一个为最小下标
	2. 遍历后面的下标, 如果更小就记录
	3. 交换两数, 在循环中重复该过程.

```java
//选择
public static void selectionSort(int[] arr){
	if (arr == null || arr.length < 2){
		return;
	}
	for (int i=0; i<arr.length-1; i++){
		int minIndex = i;
		for(int j = i+1; j<arr.length; j++){
			minIndex = arr[j] < arr[minIndex] ? j : minIndex;
		}
		swap(arr, i, minIndex);
	}
}
```

- 时间复杂度: O(n ^ 2);
- 空间复杂度: O(1);
- 稳定性: 无

## 冒泡排序 **排序算法**

1. 思路:
	1. i 表示冒泡的范围, 逐渐往左缩进
	2. 从左向右冒泡, 如果左数大于右数, 就交换.

```java
//冒泡
public static void bubbleSort(int[] arr) {
	if (arr == null || arr.length < 2) {
		return;
	}
	for (int i = arr.length - 1; i > 0; i--) {
		for (int j = 0; j < i; j++) {
			if (arr[j] > arr[j + 1]) {
				swap(arr, j, j + 1);
			}
		}
	}
}
```

- 时间复杂度: O(n ^ 2)
- 空间复杂度: O(1)
- 稳定性: 有

## 插入排序 **排序算法**

1. 思路
	1. 从第一个数开始遍历到 n - 1 个数 (等待插入的数)
	2. 从后往前, 如果前数比该数大, 就交换

```java
//插入
public static void insertSort(int[] arr) {
    if (arr == null || arr.length < 2) {
        return;
    }
    for (int i = 1; i < arr.length; i++) {
        for (int j = i - 1; j >= 0; j--) {
            if (arr[j] > arr[j + 1]) {
                swap(arr, j, j + 1);
            }
        }
    }
}
```

- 时间复杂度: O(n ^ 2)
- 空间复杂度: O(1);
- 稳定性: 有

# 3. 二分法

## 二分法的基本介绍

1. 前提有序数组
2. 时间复杂度为 O(log2(N));

## 找有序数组中的某个数

1. 思路: 这个数不一定存在, 所以最后要进行判空
2. 找到两个端, L, R 和 mid(注意不要越界)
3. 当 L < R 时, 循环继续
4. 最后判一下 arr[L] 是不是与 target 相等

```java
//找有序数组中的某个数
public int findOne(int[] arr, target){
	if(arr == null || arr.length == 0){
		return null;
	}
	int L = 0;
	int R = arr.length - 1;
	int mid = 0;
	while(L < R){
		mid = L + ((R - L) >> 1);
		if(arr[mid] == target){
			return mid;
		}
		if(arr[mid] > target){
			R = mid - 1;
		}else{
			L = mid + 1;
		}
	}
	if(arr[L] == target){
		return L;
	}
	return null
	//根据需要还可以返回boolean类型的值 
	//return arr[L] == target;
}
```

## 找有序数组的中的大于等于某个数的最左侧位置

- 思路:
1. 这个位置一定存在, 所以不断更新即可
2. 一定要给一个循环退出的绝对条件 (小于等于)

```java
public int getBiggerMostLeft(int[] arr, int target){
	int L = 0;
	int R = arr.length - 1;
	int mid = 0;
	int resIndex;
	while(L <= R){
		mid = L + ((R - L) >> 1);
		if(arr[mid] >= target){
			resIndex = mid;
			R = mid - 1;
		}else{
			L = mid + 1;
		}
	}
	return resIndex;
}
```

## 找有序数组的中的小于等于某个数的最右侧位置

- 思路
1. 与上面一样, 这个位置一定存在

```java
public int lessEqualMostRight(int[] arr, int target){
```

## 局部最小值问题

- 问题描述: 什么是局部最小?
1. 0 位置比 1 位置小
2. N 位置 比 N - 1 位置小
3. i 位置比 i - 1 位置小, 且比 i + 1 位置小

- 思路:
1. 先看 0 位置, 判断是不是
2. 再看 N - 1 位置, 判断是不是
3. 如果情况 1 和情况 2 都不满足, 那中间一定存在局部最小, 用二分法判断

![[附件/image/01_认识复杂度_对数器_二分法_认识异或运算.jpg]]

```java
//寻找局部最小
//length >= 2
public int findPartSmall(int[] arr){
	int n = arr.length;
	if(arr[0] < arr[1]){
		return 0;
	}
	if(arr[n - 1] < arr[n - 2]){
		return n - 1;
	}
	int L = 0;
	int R = n - 1;
	int mid = 0;
	while(L < R){
		mid = L + ((R - L ) >> 1);
		if(arr[mid] > arr[mid + 1]){
			L = mid + 1;
		}else if(arr[mid] > arr[mid - 1]){
			R = mid - 1;
		}else{
			return mid;
		}
	}
	return L;
}
```

# * 认识**异或**运算 **异或**

**异或**理解: 不进位的加法

## 三方完成变量的交换 **异或**

- 问题描述: 不用其他变量, 完成交换
- 思路: **异或**运算
- 代码:

```java
	a = a ^ b;
	b = a ^ b;
	a = a ^ b;
    ⚠️注意: 数组交换时 下标不能重合
```

## 出现奇数次的数字 **异或**

- 问题描述: 一个数组中, 只有一个数字出现奇数次, 找到这个数
- 思路: **异或**自己等于 0
- 代码:

```java
	int eor = 0;
	for(int i = 0; i < n; i++){
		eor ^= arr[i];
	}
	return eor;
```

## 找到某数二进制最右侧的非空数 **位运算**

- 问题描述: 找到最右侧的 1
- 思路: 找到一个数与它与, 得到最右侧的 1: 取反加 1
- 代码

```java
	int eor = a & (~a + 1)
```

## 找到两个出现奇数次的数 **异或**

- 问题描述: 数组中有两个数出现奇数次, 找到他们
- 思路:
	1. 先全**异或**, 获得 a ^ b
	2. 将这个数的最右侧的 1 取出来, 因为 a b 不等, 所以必然有这样一个数 rightOne
	3. 遍历数组与 eor 相与, 其中必然有存在 a 的一组和存在 b 的一组, 将其区分
	4. 分别完成找到那个出现奇数次的数即可.
- 代码

```java
	int num = a ^ b;
	int rightOne = num & (~num + 1);
	int eor = 0;
	for(int i = 0; i < n; i++){
		if(rightOne & arr[i] != 0){
			//得到一个数
			eor = eor ^ arr[i];
		}
	}
	b = eor ^ num;
```
