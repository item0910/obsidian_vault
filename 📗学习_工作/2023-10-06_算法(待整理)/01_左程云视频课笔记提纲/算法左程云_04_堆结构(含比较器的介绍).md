# 堆结构

## 堆中任意单位在数组中的位置

- 数组表示: 0 开始的实现:
	- 左: 2 * i + 1
	- 右: 2 * i + 2
	- 父: (i - 1) / 2

- 数组表示: 1 开始的实现 (可以利用位运算, 可以加速运算):
	- 左: 2 * i
	- 右: 2 * i + 1;
	- 父: i / 2

## 堆的定义

- 大根堆: 每一颗子树最大值都是头节点的值
- 小根堆: 每一颗子树最小值都是头节点的值

## 组织一个大根堆 (heapInsert)

- 思路:
	- 新来的数先放在 heapSize 上
	- heapInsert(往上看)

## 把堆中的最大值删除并重新组织 (heapify)

- 思路:
	- 取出 0 位置的数返回
	- 把最后一个数放到 0 位置, heapSize--
	- 把 0 位置的数 heapify 下来
		- heapify 过程, 比较左右孩子中较大的那个, 和自身交换.
- 代码

```java
public int pop(int[] heap){
	int res = heap[0];
	swap(heap, 0, --heapSize);
	heapify(heap, 0, heapSize);
	return res;
}

public void heapify(int[] heap, int index, int heapSize){
	int left = index * 2 + 1;
	while(left < heapSize){
		int largest = (left + 1 < heapSize) && (heapSize[left + 1] > heapSize[left]) ? left + 1 : left;
		largest = heap[largest] > heap[index] ? largest : index;
		if(largest == index){
			break;
		}else{
			swap(heap, largest, index);
			index = largest;
			left = index * 2 + 1;
		}
	}
}
```

## 堆排序

堆排序只会保证第一个元素也就是根节点的元素是当前优先队列里最小（或者最大）的元素，而且每一次变化之后，比如 PriorityQueue 在 offer() 或者 poll() 之后，都会进行堆重排，所以如果想要按从小到大的顺序取出元素，那么需要用一个 for 循环，如下：
- 堆排序的优势:
	- 额外空间复杂度 O(1);

- 思路:
	1. 先把整个数组调成大根堆
		1. 从 0 - N-1 上, heapInsert
	2. 把 0 位置的数换到 N - 1 位置上 (这个数已经放好了)
	3. 然后把 0 位置的数 heapify 下去, 再进行步骤 2

```java
	public static void heapSort(int[] arr) {
		if (arr == null || arr.length < 2) {
			return;
		}
		// O(N*logN)
		//heapInsert组织大根堆
//		for (int i = 0; i < arr.length; i++) { // O(N)
//			heapInsert(arr, i); // O(logN)
//		}
		// O(N)
		//heapify组织大根堆
		for (int i = arr.length - 1; i >= 0; i--) {
			heapify(arr, i, arr.length);
		}
		int heapSize = arr.length;
		// O(N*logN)
		while (heapSize > 0 ) { // O(N)
			swap(arr, 0, --heapSize); // O(1)
			heapify(arr, 0, heapSize); // O(logN)
		}
	}
```

## 不超过 K 步的排序

- 问题描述: 已知一个几乎有序的数组。几乎有序是指，如果把数组排好顺序的话，每个元素移动的距离一定不超过 k，并且 k 相对于数组长度来说是比较小的。
- 思路:
	- 先在 0 - k 位置组织小根堆, 因为 k 步范围内这些数都有可能来到 0 位置
	- 弹出 0 位置上的数, 组织小根堆
	- 然后这个再把 k + 1 位置上的数加入进这个小根堆, 再弹出 0., 最后依次弹出
- 代码:

```java
public void sortArrDistanceLessThanK(int[] arr, int K){
	PriorityQueue<> q = new PriorityQueue<>();
	int index = 0;
	while(index <= Math.min(K, arr.length - 1)){
		//先加入K + 1个数字到小根堆中.
		q.add(arr[index]);
		index++;
	}
	int i = 0;
	while(index < arr.length){
		arr[i++] = q.poll();
		q.add(arr[index++]);
	}
	while(!q.isEmpty()){
		arr[i++] = q.poll();
	}
}
```

# 对象的值变化时的自适应堆

```java
public class Code05_GreaterHeap {
	public static class GreaterHeap<T>{
		//List做堆
		private ArrayList<T> heap;
		//用哈希表记录下标
		private HashMap<T, Integer> indexMap;
		private int heapSize;
		private Comparator<? super T> com;
		
		public GreaterHeap(Comparator<T> com){
			heap = new ArrayList<>();
			indexMap = new HashMap<>();
			heapSize = 0;
			this.com = com;
		}
		
		public boolean isEmpty(){
			return heapSize == 0;
		}
		
		public int size(){
			return heapSize;
		}
		
		public T peek(){
			return heap.get(0);
		}
		
		public boolean contains(T value){
			return indexMap.containsKey(value);
		}
		//这个方法可以改成pushOrUpdate
		public void push(T value){
			if(heap.contains(value)){
				return;
			}
			heap.add(value);
			indexMap.put(value, heapSize);
			heapInsert(heap, heapSize++);
		}
		
		private void heapInsert(ArrayList<T> heap,int index){
			while(com.compare(heap.get(index), heap.get((index - 1) / 2)) > 0  ){
				swap(heap, index, (index - 1) / 2);
				index = (index - 1) / 2;
			}
		}
		
		private void swap(ArrayList<T> heap, int index1, int index2){
			T o1 = heap.get(index1);
			T o2 = heap.get(index2);
			heap.set(index1, o2);
			heap.set(index2, o1);
			indexMap.put(o1, index2);
			indexMap.put(o2, index1);
		}
		
		public T pop(){
			if(heapSize == 0){
				throw new RuntimeException("无了");
			}
			
			T value = heap.get(0);
			swap(heap, 0, --heapSize);
			heap.remove(heapSize);
			indexMap.remove(value);
			heapify(heap, 0, heapSize);
			return value;
		}
		
		private void heapify(ArrayList<T> heap, int index, int heapSize){
			int left = 2 * index + 1;
			while(left < heapSize){
				int larger = (left + 1 < heapSize) && (com.compare(heap.get(left + 1), heap.get(left)) > 0) ? left + 1: left;
				if(com.compare(heap.get(index), heap.get(larger)) < 0){
					swap(heap, index, larger);
					index = larger;
					left = 2 * index + 1;
				}else{
					break;
				}
			}
		}
		
		public void remove(T value){
			T replace = heap.get(--heapSize);
			int index = indexMap.get(value);
			indexMap.remove(value);
			heap.remove(heapSize);
			if(replace != value){
				heap.set(index, replace);
				indexMap.put(replace, index);
				retain(replace);
			}
		}
		
		public void retain(T value){
			int index = indexMap.get(value);
			heapInsert(heap, index);
			heapify(heap, index, heapSize);
		}
	}
	

	
	public static void main(String[] args){
		Comparator<Student> com = new MyCompare();
		GreaterHeap<Student> heap = new GreaterHeap<>(com);
		int size = 100;
		
		for(int i = 0; i < 20; i++){
			int ran = (int)(Math.random() * size + 1);
			heap.push(new Student(ran));
		}
		
		for(int i = 0; i < 20; i++){
			System.out.println(heap.pop());
		}
	}
}

class MyCompare implements Comparator<Student>{

	@Override
	public int compare(Student o1, Student o2) {
		// TODO Auto-generated method stub
		return o1.id - o2.id;
	}
}

	int id;
	
	public Student(int id){
		this.id = id;
	}
	
	@Override
	public String toString(){
		return "Student:" + id;
	}
}
```
