## 链表的反转和删除节点

### 单链表的反转 **链表**

- 问题:
- 思路: 准备一个 pre 指针和 next 指针
- 代码:

```java
public Node reverse(Node head){
	if(head == null){
		return null;//以后不再判空
	}
	Node pre = null;
	Node next = null;
	while(head != null){
		next = head.next;
		head.next = pre;
		pre = head;
		head = next;
	}
	return pre;	
}
```

```java
public Node reverseDoubleNode(Node head){

		return head;
```

### 链表的删除 **链表**

- 问题:
- 思路: 准备一个 dummyHead
- 代码

```java
public Node delete(Node head, Integer val){
	if(head == null){
		return null;//以后不再判空
	}
	Node dummy = new Node(-1, head);
	Node pre = dummy;
	Node cur = head;
	while(cur != null){
		if(cur.val == val){
			pre.next = cur.next;
		}else{
			pre = cur;
		}
		cur = cur.next;
	}
	return dummy.next;	
}
```

## 链表实现栈和队列 **链表** **栈与队列**

- 问题: 用链表实现栈和队列
- 思路: 准备一个双链表,有头尾两个节点的指针, 给他准备从头加入, 从头出, 从尾入, 从尾出的方法, 然后根据需求给予相应的方法实现
- 代码

```java
public class Node(Integer val){
	public Node last;
	public Node next;
	public Integer val;
	public Node(Integer val){
		this.val = val
	}
}

public class DoubleEndsQueue{
	Node head;
	Node tail;
	
	public void addFromHead(Integer val){
		Node cur = new Node(val);
		if(head == null){
			head = node;
			tail = node;
		}else{
			cur.next = head;
			head.last = cur;
			head = cur;
		}
	}
	
	public void addFromTail(Integer val){
		Node cur = new Node(val);
		if(head == null){
			head = node;
			tail = node;
		}else{
			cur.last = tail;
			tail.next = cur;
			tail = cur;
		}
	}
	
	public void popFromHead(){
		if(head == null){
			return null;
		}
		Node cur = head;
		if(head == tail){
			head = null;
			tail = null;
		}else{
			head = head.next;
			cur.next = null;
			head.last = null;
		}
		return cur.val;
	}
	
	public void popFromLast(){
		if(head == null){
			return null;
		}
		Node cur = tail;
		if(head == tail){
			head = null;
			tail = null;
		}else{
			tail = tail.last;
			cur.last = null;
			tail.next = null;
		}
		return cur.val;
	}
	
	public boolean isEmpty(){
		return head == null;
	}
}

public class MyStack{
	public DoubleEndsQueue queue;
	
	public MyStack(){
		queue = new DoubleEndsQueue();
	}
	
	public void push(Integer val){
		queue.addFromHead(val);
	}
	
	public Integer pop(){
		queue.popFromHead();
	}
}

public class MyQueue{
	public DoubleEndsQueue queue;
	
	public MyQueue(){
		queue = new DoubleEndsQueue();
	}
	
	public void push(Integer val){
		queue.addFromHead(val);
	}
	
	public Integer poll(){
		queue.popFromLast();
	}
```

## 数组实现栈和队列 **数组** **栈与队列**

### 数组实现栈 **数组** **栈与队列**

- 问题: 数组实现栈
- 思路: 设计好栈的大小 size, 将要放的位置 index
- 代码:

```java
public class ArrayStack{
	int[] stack;
	int index;//将要放入的位置
	int size;
	
	public ArrayStack(int size){
		stack = new int[size];
		size = stack.length;
		index = 0;
	}
	
	public void push(int v){
		if(index == size){
			throw new RuntimeException("满了");
		}else{
			stack[index++] = v;
		}
	}
	public int pop(){
		if(index - 1 < 0){
			throw new RuntimeException("无了");
		}else{
			return stack[index--];
		}
	}
}
```

## 返回最小值的栈 **栈与队列**

- 问题: 设计一个栈, 其中有一个 getMin 方法.
- 思路:
	1. 准备一个同步压入弹出的栈 (stackMin), 主要是为了在这个最小栈的最顶端维护最小值
- 代码

```java
public class minStack{
	Stack<Integer> originStack;
	Stack<Integer> getMinStack;
	
	public minStack(){
		originStack = new Stack<>();
		getMinStack = new Stack<>();
	}
	
	public void push(int val){
		if(getMinStack.isEmpty()){
			getMinStack.push(val);
		}else{
			int min = getMinStack.peek() >= val ? val : getMinStack.peek();
			getMinStack.push(min);
		}
		originStack.push(val);
	}
	public int pop(){
		if(originStack.isEmpty()){
			throw new RuntimeException("无了");
		}
		getMinStack.pop();
		return originStack.pop();
	}
	
	public int getMin(){
		if(getMinStack.isEmpty()){
			throw new RuntimeException("无了");
		}
		return getMinStack.peek();
	}
}
```

## 栈和队列的互相实现

### 栈实现队列 **栈与队列**

- 问题: 用栈实现一个队列
- 思路:
	1. 准备两个栈, 放的时候正常放左边
	2. 取的时候, 如果右边的为空, 就把左边的全部倒在右边. 最后从右边的顶取 peek 同理
- 代码

```java
public static class MyQueue{
	public Stack<Integer> left;
	public Stack<Integer> right;

	public MyQueue(){
		left = new Stack<Integer>();
		right = new Stack<Integer>();
	}

	public void push(int value){
		left.push(value);
	}

	public int pop(){
		if(left.isEmpty() && right.isEmpty()){
			throw new RuntimeException("无了");
		}

		if(right.isEmpty()){
			while(!left.isEmpty()){
				right.push(left.pop());
			}
		}
		return right.pop();
	}
}
```

### 队列实现栈 **栈与队列**

- 问题: 用队列实现一个栈
- 思路:
	1. 准备两个队列, 角色为队列 1 和队列 2
	2. 放的时候, 正常放入队列 1 中
	3. 取的时候, 把队列 1 中的倒到队列 2 中去, 剩一个用作返回, 取一个零时队列, 将队列 1 和队列 2 的角色互换.
	4. peek 时, 和 pop 类似, 只是最后 poll 出来的值, 还是给队列 2 塞进去.
- 代码:

```java
public static class MyStack<T>{
	public Queue<T> q1;
	public Queue<T> q2;

	public MyStack(){
		q1 = new LinkedList<T>();
		q2 = new LinkedList<T>();
	}

	public void push(T value){
		q1.offer(value);
	}

	public T poll(){
		while(q1.size() > 1){
			q2.offer(q1.poll());
		}
		T value = q1.poll();
		Queue<T> temp = q1;
		q1 = q2;
		q2 = temp;

		return value; 
	}

	public T peek(){
		while(q1.size() > 1){
			q2.offer(q1.poll());
		}
		T value = q1.poll();
		q2.offer(value);
		Queue<T> temp = q1;
		q1 = q2;
		q2 = temp;

		return value;
	}

	public boolean isEmpty(){
		return q1.isEmpty();
	}
}
```

# 递归

## 递归找最大值 **递归** **数组**

- 问题: 找到一个数组的最大值 (logN)
- 思路:
	1. 找到中点, 找到左边的最大值和右边的最大值, 进行比较, 得到最大值
	2. Base Case: 如果 L == R, return arr[L];
- 代码

```java
public int getMax(int[] arr){
	int L = 0;
	int R = arr.length - 1;
	return getMax(arr, L, R);
}

public int getMax(int[] arr, int L, int R){
	if(L == R){
		return arr[L];
	}
	int mid = L + ((R - L) >> 1);
	return Math.max(getMax(arr, L, mid), getMax(arr, mid + 1, R);
}
```

## 递归行为的时间复杂度

### Master 公式

公式为：T(N) = a * T(N/b) + O(N ^ d);
其中: a 为子问题调用的次数, 这里是 2; b 为子问题的规模, 这里是 1/2(b = 2), 剩余为除了递归行为剩余的行为, 这里是 O(1)(d = 0);
所以在这个问题中, T(N) = 2 * T(N / 2) + O(1), 满足条件
这种递归的复杂度为:

- if logb(a)<d ,then T(N)=O(N^d)
- if logb(a)>d ,then T(N)=O(N^logb(a))
- if logb(a)=d ,then T(N)=O(N^d*(logN))
