# 图的通用数据结构

- Node
	- 属性
		- int in: 入点个数
		- int out: 出点个数
		- int id: 值或编号
		- List< Edge> edges: 出边的集合
		- List< Node> nodes: 出点的集合
	- 构造方法 (初始化):
- Edge
	- 属性:
		- int weight 权重
		- Node from 这头
		- Node to 那头
	- 构造方法 (初始化):
- Graph
	- 属性:
		- HashMap< Integer, Node> nodes: 点的集合
		- HashSet< Edge> edges: 边的集合
	- 构造方法 (初始化)
- Graph 的建立 (遍历 int[][] matrix)
	- 思路: graph 中含有什么?
	- 步骤, 判断 node 是否存在, 往 graph 中放入 node
	- 拿出 node, 建立边
	- 添加 node 的属性
	- 把边加到 graph 中

# 图的遍历:

## 宽度优先遍历

- 判断是否为空
- 准备一个 queue 用来弹打; 一个 set 用来判断是否入过队列

## 深度优先遍历

- 判断是否为空
- 准备一个 stack 和一个 set
	- stack 用来打入栈
	- set 判断如果 node 的 next 没打印过, 那么将此 node 和 next 依次压入, 并打印,添加 set, 并终止该次 nexts 的遍历

## 拓扑排序

- 将 node 和其 in 放在一个 Map< Node, in>中
	- 当该 node 的 in 为 0 时, 放入队列中
- 从队列中取出一个 node, 并将其 nexts 的 in 全部减 1
	- 再次进行判断 in, 若为 0 , 则放入队列中, 直到队列为空.

## 最小生成树算法 Kruskal

- 准备一个以边从小到大的小根堆, 将边全部放入
	- 需要一个 EdgeComparator implentments Comparator< Edge>
- 用一个并查集来包裹 nodes
- 遍历小根堆里的 Edge, 如果不是同一个交集 (isSameSet), 就 union 他们. 并将该 edge 放入事先准备好的 HashSet result 中.
- 返回该 set

## 最小生成树算法 Prim

- 准备一个小根堆放边 queue
- 准备两个用来判断是否遍历过的 HashSet
	- selectedNodes 遍历完的点
	- selectedEdges 遍历过的边
- 任从一点开始 (将该点加入 sN), 遍历所有边 (可以添加 for node : 防森林)
	- 如果 sE 中不含这些边, 那么放入小根堆, 并在 sE 中添加
	- 当队列不为空时
		- 弹得边, 边 to 作为新的节点, 如果 sN 中不含这个点, 那么遍历这个点的 nexts, 同样的逻辑进行添加边和加队列.

## 单元最短路径算法 Dijkstra

- 准备一个 distanceMap,HashMap< Node, Integer> 代表选择点到各个点的当前距离
- 准备一个 selectedNodes(HashSet< Node>) 作为已经选择过的点
- 先把头结点放进去, put(node, 0); 其他的点不放, 代表无限大距离
- 进行 Node minNode = getMinDistanceNode(distanceMap, selectedNodes) 过程, 找到离当前点最短的且未进行过判断的点.
	- getMinDistanceNode
		- 从 distanceMap 中遍历所有的 Entry<Node, distance>
			- key = Node
			- value = distance
		- 更新 minNode 条件:!selectedNodes.contains(node) && distance < minDistance: 满足条件, 更新 minNode
		- 返回 minNode
- 更新 distanceMap:
	- 获取 minNode 的 distance: distanceMap.get(minNode);
	- 遍历 minNode 的 edges, 更新 to 节点在 distanceMap 的数据:
		- 如果数据不存在, 那么添加 distance + edge.weight 作为数据
		- 如果存在, 那么更新 Node, Math.min(distanceMap.get(node), distance + edge.weight)
	- 标记 minNode 进 selectedNode
	- 换下一个 minNode = getMinDistanceNode

## 用加强堆做 Dijkstra 更好的实现

- 思路, 每次都要遍历 distanceMap 来找最小的, 能不能把这步简化
- 准备一个堆, 当点的 distance 关系发生变化时, 就能将其放在合适的位置, 由此直接拿出最短距离的点而无需再遍历.
