# 得到一个任意窗口 (L,R) 的最大值

- 核心: 准备一个双端队列.
	- 放下标, 从大到小
		- R 动时:
			- 从尾巴进元素
			- 是不是满足单调性, 满足则从尾巴进入; 如果放不了, 从尾巴弹出, 直到可以放进 (等于的情况也弹出), 弹出不找回.
		- L 动时:
			- 从头部弹元素
			- 过期位置是否头部节点位置, 如果是, 则弹出.如果不是, 则不用管

![[附件/image/17 滑动窗口.jpg]]

```java
package class013;

import java.util.LinkedList;

/**
 * @author Item
 */
public class Code06_MaxWindow {
    public static class WindowMax{
        private int L;
        private int R;
        private int[] arr;
        private LinkedList<Integer> qmax;

        public WindowMax(int[] a){
            arr = a;
            L = -1;
            R = 0;
            qmax = new LinkedList<>();
        }
		
        public void addNumFromRight(){
            if(R == arr.length){
                return;
            }
            while(!qmax.isEmpty() && arr[qmax.peekLast()] <= arr[R]){
                qmax.pollLast();
            }
            qmax.addLast(R);
            R++;
        }

        public void removeFromLeft(){
            if(L >= R - 1){
                return;
            }
            L++;
            if(qmax.peekFirst() == L){
                qmax.pollFirst();
            }
        }

        public Integer getMax(){
            if(!qmax.isEmpty()){
                return arr[qmax.peekFirst()];
            }
            return null;
        }
    }

    public static int[] getMaxWindow(int[] arr, int w){
        if(arr == null || arr.length == 0 || w < 1){
            return null;
        }
        LinkedList<Integer> qmax = new LinkedList<>();
        int[] res = new int[arr.length - w + 1];
        int index = 0;
        for (int i = 0; i < arr.length; i++) {//R
            while(!qmax.isEmpty() && arr[qmax.peekLast()] <= arr[i]){
                qmax.pollLast();
            }
            qmax.addLast(i);
            if(qmax.peekFirst() == i - w){//i - w 就是过期的下标(L 的左边一个)
                qmax.pollFirst();
            }
            if(i >= w - 1){//此时窗口形成
                res[index++] = qmax.peekFirst();
            }
        }
        return res;
    }
}
```

# 单调栈: 了解数组中每个数左右离他最近的比他大的数

先看没有重复项的情况:

- 准备一个底大顶小的栈
- 依次将数组中的元素放入, 如果能维持栈的单调性, 则直接放入
- 如果不能, 则从栈弹出的元素即生成信息, 当前要入栈的元素即为右边最近的比其大的元素, 弹出元素下面一个 (栈底下一个) 即为左边最近的比其大的元素
- 结束时, 直接弹出, 并生成信息.
![[附件/image/17 滑动窗口-1.jpg]]

再看有重复项的情况
- 压入的时候, 值相等, 下标压在一起 (依次)
- 弹出的时候, 从左往右弹出: 右边离他最近的比他大的就是当前要入站的元素, 左边离他最近比他大的就是底下最右边的元素.
