# 安排会议室

- 策略 1: 时间短的先安排 (反例: 一个短的把两个长的挤掉了)
- 策略 2: 先开的先安排 (反例: 一个很长时间的会)
- 策略 3: 先结束的先安排

```java
package class009;

import java.util.Arrays;
import java.util.Comparator;

/**
 * @author Item
 */
public class Code01_ArrangeMeeting {
    public static class Meeting {
        int startTime;
        int endTime;

        public Meeting(int startTime, int endTime) {
            this.startTime = startTime;
            this.endTime = endTime;
        }
    }
	//暴力递归的方法
    public static int arrangement1(Meeting[] meetings) {
        if (meetings == null || meetings.length == 0) {
            return 0;
        }
        return process(meetings, 0, 0);
    }

	//参数说明: left, 尚未处理的会议, done, 已经处理的会议, endTime, 已经处理到几点钟了.
    public static int process(Meeting[] left, int done, int endTime) {
        if (left.length == 0) {
            return done;
        }
        int max = done;
        for (int i = 0; i < left.length; i++) {
            //每个能安排的, 都安排试试, 最后找出最大的.
			if (left[i].startTime >= endTime) {
                Meeting[] newLeft = copyButExcept(left, i);
                //下面的分支要分开更新max
				//可以画一个递归图来分析一下
                max = Math.max(max, process(newLeft, done + 1, left[i].endTime));
            }
        }
        return max;
    }
	//安排完了, 去掉下标为index的一个
    public static Meeting[] copyButExcept(Meeting[] res, int index) {
        Meeting[] tar = new Meeting[res.length - 1];
        int tarIndex = 0;
        for (int i = 0; i < res.length; i++) {
            if(i != index) {
                tar[tarIndex++] = res[i];
            }
        }
        return tar;
    }

    //贪心算法 : 按结束时间排序
    public static int arrangement2(Meeting[] meetings) {
        if (meetings == null || meetings.length == 0) {
            return 0;
        }
        int max = 0;
        int timeLine = 0;
		//直接排序
        Arrays.sort(meetings, new MyCom());
        for (int i = 0; i < meetings.length; i++) {
            if (timeLine <= meetings[i].startTime) {
                max++;
                timeLine = meetings[i].endTime;
            }
        }
        return max;

    }
	//比较器
    public static class MyCom implements Comparator<Meeting> {
        @Override
        public int compare(Meeting o1, Meeting o2) {
            return o1.endTime - o2.endTime;
        }
    }
	//for test
    public static Meeting[] generateMeetings(int meetingCount, int timeLast) {
        Meeting[] meetings = new Meeting[(int) (Math.random() * (meetingCount + 1))];
        for (int i = 0; i < meetings.length; i++) {
            int time1 = (int) (Math.random() * (timeLast + 1));
            int time2 = (int) (Math.random() * (timeLast + 1));
            if (time1 == time2) {
                meetings[i] = new Meeting(time1, time1 + 1);
            } else {
                meetings[i] = new Meeting(Math.min(time1, time2), Math.max(time1, time2));
            }
        }
        return meetings;
    }
	//for test
    public static void main(String[] args) {
        int timeLast = 12;
        int meetingCount = 5;
        int testTime = 10000;
        System.out.println("start");
        for (int i = 0; i < testTime; i++) {
            Meeting[] meetings = generateMeetings(meetingCount, timeLast);
            if (arrangement1(meetings) != arrangement2(meetings)) {
                System.out.println("opps");
            }
        }
        System.out.println("finish");
    }
}
```

# 放灯问题

题目 : 给定一个字符串 str，只由‘X’和‘.’两种字符构成。‘X’表示墙，不能放灯，也不需要点亮。‘.’表示居民点，可以放灯，需要点亮。如果灯放在 i 位置，可以让 i-1， i 和 i+1 三个位置被点亮。返回如果点亮 str 中所有需要点亮的位置，至少需要几盏灯。

```java
package class009;

import java.util.HashSet;

/**
 * @author Item
 */
public class Code02_PutLights {
    public static int putLights1(String road){
        if(road == null || road.length() == 0){
            return 0;
        }
        return process(road.toCharArray(), 0, new HashSet<Integer>());
    }
	//参数说明: road, 当前的下标, 已经放了灯的下标
    public static int process(char[] road, int index, HashSet<Integer> record){
        //到了越界的时候(前面已经全部决策完了, 只剩判断是否符合要求)
        if(index == road.length){
            for (int i = 0; i < road.length; i++) {
                if(road[i] == '.'){
					//不符合的条件.
                    if(!record.contains(i-1) && !record.contains(i) && !record.contains(i + 1)){
                        return Integer.MAX_VALUE;
                    }
                }
            }
            return record.size();
        }else{
            //需要决策当前(因为结束点是最后, 所以可以向前传递)
            //当前不放灯.
			int no = process(road, index + 1, record);
            //当前放灯
			int yes = Integer.MAX_VALUE;
            if(road[index] == '.'){
                record.add(index);
                yes = process(road,index + 1,record);
				//添加到递归过程中的元素要移除, 可以画递归图来分析.
                record.remove(index);
            }
            return Math.min(no,yes);
        }
    }
    //贪心, 根据当前位置的情况以及i+1, i+2位置的情况判断是否需要放灯.
    public static int putLights2(String s){
        if(s == null || s.length() == 0){
            return 0;
        }
        char[] road = s.toCharArray();
        int lights = 0;
        for (int i = 0; i < road.length;) {
            if(road[i] == '.'){
                lights++;
                //把三个数看做一个整体
                i += 3;
            }else{
                i++;
            }
        }
        return lights;
    }
    //for test
    public static String generateRoad(int num){
        int length = (int)(Math.random() * num);
        char[] chars = new char[length];
        double rate = Math.random() * 1.0;
        for (int i = 0; i < chars.length; i++) {
            if(rate < 0.5){
                chars[i] = '.';
            }else{
                chars[i] = 'X';
            }
        }
        return new String(chars);
    }
    //for test
    public static void main(String[] args) {
        int length = 20;
        int testTime = 200;
        for (int i = 0; i < testTime; i++) {
            String road = generateRoad(length);
            if(putLights1(road)!= putLights2(road)){
                System.out.println("oops");
            }
        }
        System.out.println("finish");
    }


}
```

# 金块分割问题

题目：

一块金条切成两半，是需要花费和长度数值一样的铜板的。比如长度为 20 的金条，不管切成长度多大的两半，都要花费 20 个铜板。

问：一群人想整分整块金条，怎么分最省铜板？

例如，给定数组{10，20，30}，代表一共三个人，整块金条长度为 10+20+30=60。

金条要分成 10，20，30。如果先把长度 60 的金条分成 10 和 50，花费 60；再把长度 50 的金条分成 20 和 30，花费 50；一共花费 110 铜板。

但是如果先把长度 60 的金条分成 30 和 30，花费 60；再把长度 30 金条分成 10 和 20，花费 30；一共花费 90 铜板。

输入一个数组，返回分割的最小代价。

```java
package class009;

import java.util.PriorityQueue;

/**
 * @author Item
 */
public class Code03_CutGold {
    public static int cutGold1(int[] golds){
        if(golds == null || golds.length == 0){
            return 0;
        }
        return process(golds, 0);
    }
    //参数说明: arr : 金块, pre : 之前已经处理的花费.
    public static int process(int[] arr, int pre){
        if(arr.length == 1){
            return pre;
        }
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i < arr.length - 1; i++) {
            for (int j = i + 1; j < arr.length; j++) {
                //因为要分别提交给上一层来比较
            	ans = Math.min(ans, process(merge(arr, i, j), pre + arr[i] + arr[j]));
            }
        }
        return ans;
    }
    //金块切割的过程其实和金块拼接的过程是一样的. 可以看做, 任选两个进行拼接, 最后组成最长的金条.
    public static int[] merge(int[] arr, int i, int j){
        int[] newArr = new int[arr.length - 1];
        int ij = arr[i] + arr[j];
        int newIndex = 0;
        for (int k = 0; k < arr.length; k++) {
            if(k == i || k == j){
                continue;
            }
            newArr[newIndex++] = arr[k];
        }
        newArr[newIndex] = ij;
        return newArr;
    }
    //贪心: 小根堆排列, 取两个, 拼好求和放回.
    public static int cutGold2(int[] golds){
        if(golds == null || golds.length < 2){
            return 0;
        }
        PriorityQueue<Integer> queue = new PriorityQueue<>();
        for (int i = 0; i < golds.length; i++) {
            queue.offer(golds[i]);
        }
        int cost = 0;
        int cut = 0;
        while(queue.size() > 1){
            cut = queue.poll() + queue.poll();
            queue.offer(cut);
            cost += cut;
        }
        return cost;
    }
    //for test
    public static int[] generateArray(int maxSize, int maxNum){
        int size = (int)(Math.random() * (maxSize + 1));
        int[] arr = new int[size];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = (int)(Math.random() * (maxNum) + 1);
        }
        return arr;
    }
    //for test
    public static void main(String[] args) {
        int size = 5;
        int num = 20;
        int testTime = 1000;
        System.out.println("start!");
        for (int i = 0; i < testTime; i++) {
            int[] arr = generateArray(size, num);
            if(cutGold1(arr) != cutGold2(arr)){
                System.out.println("oops");
            }
        }
        System.out.println("finish");
    }
}
```

# 最大利润

```java
package class009;

import java.util.Comparator;
import java.util.PriorityQueue;

/**
 * @author Item
 */
public class Code04_MaxProfitProject {
    public static class Project{
        int cost;
        int profit;

        public Project(int cost, int profit) {
            this.cost = cost;
            this.profit = profit;
        }
    }

    public static int getMaxProfit(Project[] projects, int money, int times){
        if(projects == null || projects.length ==0 ){
            return 0;
        }
        int nowMoney = money;
        while(times > 0) {
        	//小根堆, 按照cost排列
            PriorityQueue<Project> cost = new PriorityQueue<>(new Cost());
            //大根堆, 按照利润排列
            PriorityQueue<Project> profit = new PriorityQueue<>(new Profit());
            //把能cover的全部排列进小根堆中
            for (int i = 0; i < projects.length; i++) {
                if(money >= projects[i].cost){
                    cost.offer(projects[i]);
                }
                //再按照利润, 移动到大根堆中
                while(!cost.isEmpty()){
                    profit.offer(cost.poll());
                }
            }
            if(profit.isEmpty()){
                break;
            }
            nowMoney += profit.poll().profit;
        }
        return nowMoney;
    }

    public static class Cost implements Comparator<Project>{
        @Override
        public int compare(Project o1, Project o2){
            return o1.cost - o2.cost;
        }
    }
    public static class Profit implements Comparator<Project>{
        @Override
        public int compare(Project o1, Project o2){
            return o2.profit - o1.profit;
        }
    }

}
```

# 209. 长度最小的子数组

```java
//双指针滑动窗口法
class Solution {
    public int minSubArrayLen(int s, int[] nums) {
        int n = nums.length;
        if (n == 0) {
            return 0;
        }
        int ans = Integer.MAX_VALUE;
        int start = 0, end = 0;
        int sum = 0;
        while (end < n) {
            sum += nums[end];
            while (sum >= s) {
                ans = Math.min(ans, end - start + 1);
                sum -= nums[start];
                start++;
            }
            end++;
        }
        return ans == Integer.MAX_VALUE ? 0 : ans;
    }
}
```

```java
class Solution {
    public static int minSubArrayLen(int target, int[] nums) {
        if ((nums == null) || (nums.length == 0)) {
            return 0;
        }

        int res = process(nums, 0, target);

        if (res == Integer.MAX_VALUE) {
            return 0;
        }

        return res;
    }
	
    public static int process(int[] arr, int index, int target) {
        int n = arr.length;

        if (index == (arr.length - 1)) {
            if (arr[index] >= target) {
                return 1;
            } else {
                return Integer.MAX_VALUE;
            }
        }

        //不在其中
        int out = process(arr, index + 1, target);

        //在其中
        int in = Integer.MAX_VALUE;
        int sum = 0;

        for (int i = index; i < arr.length; i++) {
            sum += arr[i];

            if (sum >= target) {
                in = i - index + 1;

                break;
            }
        }

        return Math.min(in, out);
    }
}
```

# 904 采水果


```java
class Solution {
    public int totalFruit(int[] tree) {
        int ans = 0, i = 0;
        Counter count = new Counter();
        for (int j = 0; j < tree.length; ++j) {
            count.add(tree[j], 1);
            while (count.size() >= 3) {
                count.add(tree[i], -1);
                if (count.get(tree[i]) == 0)
                    count.remove(tree[i]);
                i++;
            }

            ans = Math.max(ans, j - i + 1);
        }

        return ans;
    }
}

class Counter extends HashMap<Integer, Integer> {
    public int get(int k) {
        return containsKey(k) ? super.get(k) : 0;
    }

    public void add(int k, int v) {
        put(k, get(k) + v);
    }
}
```

```java
思路:
    类似于滑动窗口的多指针解法
    我们需要在遍历tree,索引为i时,不断更新以下三个指针:
    当下的两个篮子第一个篮子起始索引first,
    当下的两个篮子第二个篮子起始索引second,
    未来的两个篮子第一个篮子的起始索引temp,
    计算两个篮子中i - first + 1的最大值即可求出水果最大长度len
如何计算first:
    遍历tree记录第一个出现的篮子的索引,
    当遍历到出现第三个篮子时(tree[i] != tree[first] && tree[i] != tree[second])将其更新为temp,
    first = temp,保证计算len时同时出现的只有两个篮子
如何计算second:
    遍历tree记录第二个出现的篮子的索引,
    当遍历到出现第三个篮子时(tree[i] != tree[first] && tree[i] != tree[second])将其更新为i,
    second = i,保证计算len时同时出现的只有两个篮子
如何计算temp:
    以010123为例，
    遍历完索引为3（值为1）时(只有两个篮子)，first = 0，second = 1，temp = 3。
    遍历完索引为4（值为2）时(出现三个篮子)，first = 3，second = 4，temp = 4。
    以010023为例，
    遍历完索引为3（值为0）时(只有两个篮子)，first = 0，second = 1，temp = 2。
    遍历完索引为4（值为2）时(出现三个篮子)，first = 2，second = 4，temp = 4。
    有如下规律:
    当下两个篮子中最后出现的篮子从后往前连续相等最长的起始索引,即为未来的两个篮子中第一个篮子的起始索引
    0101最后出现的篮子是1索引是3,和1从后往前连续相等最长的索引还是3
    0100最后出现的篮子时0索引是3,和0从后往前连续相等最长的索引是2

class Solution {
    public int totalFruit(int[] tree) {
        if (tree.length == 0) {
            return 0;
        }
        int len = 0,first = 0,second = 0,temp = 0;
        for (int i = 0; i < tree.length; i++) {
            //判断是否出现第三个篮子
            if (tree[i] != tree[first] && tree[i] != tree[second]){
                //只有初始化时,第一个篮子和第二个篮子都为0时才相等
                //相等时出现的是第二个篮子,故不用更新first,只需要更新second
                //不相等时出现的是第三个篮子,故first,second都需要更新
                if(first != second) {
                    first = temp;
                }
                second = i;
            }
            //更新len最大值
            len = Math.max(len,i - first + 1);
            //计算temp
            if(tree[temp] != tree[i]){
                temp = i;
            }
        }
        return len;
    }
}
```
