# KMP(最长相同字符子串匹配)

- str2, 获得一个每个字符位置之前的字符串的, 最小相同的字符串, 由这个数字组成一个数组 int[]
	- 比如 aabaabm, 这个数组就为:{-1, 0, 1, 0, 1, 2, 3}
- 加速过程, 匹配到第一个不相同的位置, 根据 str2 这个在之前数组中的最大匹配值, 跳到 str2 的前位置, 继续进行匹配
![[附件/image/16 字符串.jpg]]
- getNextArray 过程:
	- 根据 i - 1 位置的值和 i - 1 位置的字符, 来推测 i 位置的值
		- 如果 i - 1 位置的字符, 与 cn 位置的字符相等 (需要进行比较的位置), 该位置就为 next[i - 1] + 1;
		- 如果不等, 则 cn 跳到 next[cn] 位置, 继续该过程比较
		- 当 cn == 0 时, next[i] == 0, i++

```java
package class013;

/**
 * @author Item
 */
public class Code04_KMP {
    public static int kmp(String s, String m){
        if(s == null || m == null || m.length() < 0 || s.length() < m.length()){
            return 0;
        }
        char[] str1 = s.toCharArray();
        char[] str2 = m.toCharArray();
        int i1 = 0;
        int i2 = 0;
        int[] next = getNextArray(str2);
        while(i1 < str1.length && i2 < str2.length){
            if(str1[i1] == str2[i2]){
                i1++;
                i2++;
            }else if(i2 == 0){
                i1++;
            }else{
                i2 = next[i2];
            }
        }
        return i2 == str2.length ? i1 - i2 : -1;
    }

    public static int[] getNextArray(char[] s){
        if(s.length == 1){
            return new int[]{-1};
        }
        int[] next = new int[s.length];
        next[0] = -1;
        next[1] = 0;
        int i = 2;//next数组的位置
        int cn = 0;//拿哪个位置的字符与i - 1比; 也代表next[i - 1]的值
        while(i < s.length){
            if(s[i - 1] == s[cn]){
                /**
                 *  next[i] = cn + 1;
                 *  i++;
                 *  cn++;
                 */
                next[i++] = ++cn;
            }else if(cn > 0){
                cn = next[cn];
            }else{
                next[i++] = 0;
            }
        }
        return next;
    }
}

```

# Manacher(买那车) 最长回文子串

- 加判断子串 '#'(并不需要不是原字符串的字符, 因为加的只会和加的比较)
- 外扩之后 除 2
- ![[附件/image/16 字符串-1.jpg]]

- manacher 过程:
	- 回文半径数组: 2 -> 4
	![[附件/image/16 字符串-2.jpg]]
	- 回文最右边界: R 实时更新

- 情况分类:
	- i 当前位置, 在 R 外: 暴力扩
	- i 位置, 在 R 内:
		- 找到 i 位置关于 c 的对称点: i'
			- i' 的回文串在 L 内, i 的值就是 i' 的值
			- i' 的回文串在 L 外, i 的值就是 i 到 R 的值
			- ![[附件/image/16 字符串-3.jpg]]
			- i' 的回文串在 L 上, i 的值从 R 继续往外扩

```java
package class013;

/**
 * @author Item
 */
public class Code05_ManacherString {
    public static char[] manacherString(String str){
        char[] charArr = str.toCharArray();
        char[] res = new char[str.length() * 2 + 1];
        int index = 0;
        for (int i = 0; i < res.length; i++) {
            res[i] = (i & 1) == 0 ? '#' : charArr[index++];
        }
        return res;
    }

    public static int maxLcpsLength(String s){
        if(s == null || s.length() == 0){
            return 0;
        }
        char[] str = manacherString(s);
        int[] pArr = new int[str.length];//表示回文半径的数组
        int C = -1;//回文中心位置
        int R = -1;//回文右边界再右边一个位置(最右有效区是R-1位置)
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < str.length; i++) {
            //i的至少值(几种情况瓶颈的中和)
            pArr[i] = R > i ? Math.min(pArr[2 * C - i], R - i) : 1;
            //不管是哪一种情况, 继续验
            while(i + pArr[i] < str.length && i - pArr[i] > -1){
                if(str[i + pArr[i]] == str[i - pArr[i]]){
                    pArr[i]++;
                }else{
                    break;
                }
            }
            //更新二数
            if(i + pArr[i] > R){
                R = i + pArr[i];
                C = i;
            }
            max = Math.max(max, pArr[i]);
        }
        return max - 1;
    }
}
```
