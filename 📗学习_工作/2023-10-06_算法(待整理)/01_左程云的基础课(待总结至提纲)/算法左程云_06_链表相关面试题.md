# 快慢指针

- 输入链表头节点，奇数长度返回中点，偶数长度返回上中点; 输入链表头节点，奇数长度返回中点，偶数长度返回下中点; 输入链表头节点，奇数长度返回中点前一个，偶数长度返回上中点前一个; 输入链表头节点，奇数长度返回中点前一个，偶数长度返回下中点前一个

> 以上问题, 统一用快慢指针解决

# 给定一个单链表的头节点 head，请判断该链表是否为回文结构

- 额外空间 O(N) 的方法和 O(N/2) 方法: 栈
- 先用快慢指针找到中点和中点右边的点, 然后倒序右边; 进行判断, 完成后, 再把右边倒回来

# 链表 partition

给定一个单链表的头节点 head，给定一个整数 n，将链表按 n 划分成左边< n、中间 == n、右边 > n

- 额外空间 O(N) 方法, 准备一个数组, 做 partition
- 准备六个指针, sH, sT, eH, eT, mH, mT;
	- 完了把他们连在一起
	- 笨办法, 加权 switch;

```java
	if(sH != null){
		sT.next = eH;
		eT = eT != null ? eT : sT;
	}

	if(eH != null){
		eT.next = mH;
	}

	return sH != null ? sH : (eH != null ? eH : mH); 
```

# 复制链表

一种特殊的单链表节点类描述如下 class Node { int value; Node next; Node rand; Node(int val) { value = val; } } rand 指针是单链表节点结构中新增的指针，rand 可能指向链表中的任意一个节点，也可能指向 null 给定一个由 Node 节点类型组成的无环单链表的头节点 head，请实现一个函数完成这个链表的复制 返回复制的新链表的头节点，要求时间复杂度 O(N)，额外空间复杂度 O(1)

- 一种方法: map
- 另一种方法, 新建节点插入中间
	- 第一步, 插入
	- 第二步, 复制 random 指针
	- 第三步, 分离链表

# 两链表相遇问题

- 如何寻找 loop
	- 快慢指针, 若二者有相遇点, 则当二者相遇时, 快指针回到原点, 按步长为 1 与慢指针相遇, 相遇点即为 loop 点

根据是否有 loop, 寻找 intersection 的点

- 都没有 loop,
	- 先看 end 节点是否相同, 如果相同, 那么统一步长, 当二者相遇时, 即为 intersection 点
- 两个都有 loop
	- loop 点相同, 计算到 loop 点的步长, 转化为都没有 loop 来解决
	- loop 点不同, 让其中一个从 loop1 点出发, 看是否能遇到 loop2 点,如果能遇到, 则返回; 不能, 则为 null;

# 只给地址能否删除一个节点

不能完全删除, 因为节点引用包含的只是指针, 即使将其置为 null, 并不能使其他节点的指向不指向该节点, 也就无法通过垃圾回收清理该内存.
