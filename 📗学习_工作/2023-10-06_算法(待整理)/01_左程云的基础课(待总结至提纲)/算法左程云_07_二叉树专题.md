# 二叉树的递归遍历

```java
package class007;

public class Code01_RecursiveTravelBT {
	//TreeNode
	public static class Node{
		int value;
		Node left;
		Node right;

		public Node(int v){
			value  = v;
		}
	}
	//递归方式
	public void pre(Node head){
		//先序打印所有节点: 头 左 右
		if(head == null){
			return;
		}

		System.out.println(head.value);
		pre(head.left);
		pre(head.right);
	}

	public void mid(Node head){
		//中序打印所有节点: 左 头 右
		if(head == null){
			return;
		}

		pre(head.left);
		System.out.println(head.value);
		pre(head.right);
	}

	public void post(Node head){
		//后序打印所有节点: 左  右 头
		if(head == null){
			return;
		}

		pre(head.left);
		pre(head.right);
		System.out.println(head.value);
	}

}
```

# 二叉树的非递归遍历

## 先序 (头左右)

- 需要一个栈
1. 先放头进去
2. 进入循环 (如果栈不空)
	1. pop 打印
	2. 如果有右, 栈放入右
	3. 如果有左, 栈放入左

## 先看后序 1(左右头 ->reverse(头右左))

- 准备 2 个栈. 一个执行 " 头右左 " 的动作 (先序左右倒过来), 另外一个栈接受第一个栈的 pop

## 后序 2(左右中)

- 准备一个跟踪工作的指针
	- 栈空判断:
		- 左不为空, 且左未处理且右未处理 (左右都未处理): 先压栈左边
		- 右不为空, 且右未处理: 先压栈右边
		- 上面两个条件都不成立: 说明需要处理自身了, 将处理标记指向栈顶 (即将处理的节点) , 处理完成后, 将 c 也指向栈顶.

## 中序

- 需要一个栈
1. 循环条件: while(!stack.isEmpty() || head != null)
	1. if( head != null) 将整条左枝依次压入栈
		1. 压入
		2. head = head.left
	2. else : !stack.isEmpty()
		1. 弹打
		2. head = head.right;(即: 前一个 if 无法执行, 来到弹出节点的右边, 继续执行条件 1)

```java
package class007;

import java.util.Stack;

public class Code02_UnRecuriveTravelBT {
	public static class Node{
		int value;
		Node left;
		Node right;
		
		public Node(int value){
			this.value = value;
		}
	}
	
	public static void pre(Node head){
		if(head == null){
			//打印空
			return;
		}
		//头 左 右
		Stack<Node> stack = new Stack<>();
		stack.add(head);
		while(!stack.isEmpty()){
			head = stack.pop();
			System.out.print(head.value + " ");
			if(head.right != null){
				stack.push(head.right);
			}
			if(head.left != null){
				stack.push(head.right);
			}
		}
		System.out.println();
	}
	
	//Double Stack方法
	public static void pos1(Node head){
		if(head == null){
			//打印空
			return;
		}
		Stack<Node> stack = new Stack<>();
		Stack<Node> help = new Stack<>();
		stack.push(head);
		while(!stack.isEmpty()){
			Node node = stack.pop();
			help.push(node);
			head = node;
			if(head.right != null){
				stack.push(head.right);
			}
			if(head.left != null){
				stack.push(head.left);
			}
		}
		while(!help.isEmpty()){
			System.out.print(help.pop() + " ");
		}
		
	}
	
	public static void mid(Node head){
		if(head == null){
			//打印空
			return;
		}
		Stack<Node> stack = new Stack<>();
		//左 头 右
		while(head != null || !stack.isEmpty()){
			if(head != null){
				stack.push(head);
				head = head.left;
			}else{
				head = stack.pop();
				System.out.print(head.value + " ");
				head = head.right;
			}
		}	
	}
	
	public static void pos2(Node h){
		if(h == null){
			return;
		}
		Stack<Node> stack = new Stack<>();
		Node c = h;
		stack.push(h);
		Node handled = null;
		while(!stack.isEmpty()){
			if(c.left != null && c.left != handled && c.right != handled){//判断去左边进行工作的条件
				stack.push(c.left);
				c = c.left;
			}else if(c.right != null && c.right != handled){//判断去右边工作的条件
				stack.push(c.right);
				c = c.right;
			}else{//左右两边都处理完了
				//标记一下当前打印的对象
				handled = stack.peek();
				System.out.println(stack.pop() + " ");
				//c需要往上返回
				if(!stack.isEmpty()){
					c = stack.peek();
				}
			}
		}
	}
	
	
}

```

### 求最大宽度

#### 用 map

- 参数:
	- map< Node, Integer>
	- curLevel = 1: 当前的工作层
	- curLevelWidth = 0: 当前层宽度
	- max = 1;
	- queue(遍历用)
- 动作:
	- 先存一个首节点 (head, 1)
		- 进入循环 (队列不为空)
		- cur = poll()
		- 循环内变量 curNodeLevel = map.get(cur)
		- 有左就加左, 同时, map 记录该左节点的位置 curNodeLevel+1
		- 右边同理
		- 如果 curLevel == curNodeLevel
			- 还在同一层, width++
		- 否则: 不在同一层了 (curNodeLevel) 大了
			- max 更新
			- curLevel++
			- curWidth = 1; 因为此时已经是新层的第一个节点了
	- 最后还要更新一次 max; 因为栈空了之后下不去了

#### 不用 map

- 参数:
	- 当前最后 curEnd
	- 下层最后 nextEnd
	- queue 遍历用
	- max
	- curWidth
- 动作: 把第一个加入队列
	- 进入循环
		- 遍历一样, 但是要不断更新 nextEnd
		- 最后 width++
		- 如果 cur == curEnd 那么进行一次结算
			- max
			- width 归零
			- curEnd = nextEnd;

```java
package class007;

/**
 * @author Item
 */
public class Code04_MyTreeWidth {
    public static class Node {
        int value;
        Node left;
        Node right;

        public Node(int v) {
            this.value = v;
        }
    }

    public static int getMaxTreeWidthWithMap(Node h) {
        if (h == null) {
            return 0;
        }
        Queue<Node> queue = new LinkedList<>();
        queue.add(h);
        HashMap<Node, Integer> map = new HashMap<>();//保存每个节点的所在层数信息
        int curCountLevel = 1;//代表当前正在数的层数
        int curWidth = 0;//用来累加当前层数的宽度
        map.put(h,1);
        int max = 0;
        while(!queue.isEmpty()){
            Node cur = queue.poll();
            int curNodeLevel = map.get(cur);
            if(cur.left != null){
                map.put(cur.left, curNodeLevel + 1);
                queue.add(cur.left);
            }
            if(cur.right != null){
                map.put(cur.right, curNodeLevel + 1);
                queue.add(cur.right);
            }
            if( curNodeLevel == curCountLevel){
                curWidth++;
            }//代表已经不在处理当前这一层了
            else {
                curCountLevel++;
                //每到新一层时, 做一些更新和初始化的工作
                max = Math.max(max, curWidth);
                curWidth = 1;
            }
        }
        //因为最后到不了最后一次else, 所以需要单独抓一下上层的记录
        max = Math.max(max,curWidth);

        return max;
    }

    public static int getMaxTreeWidthWithoutMap(Node h){
        if (h == null){
            return 0;
        }
        Node curEnd = h;
        Node nextEnd = null;
        Queue<Node> q = new LinkedList<>();
        q.add(h);
        int max = 0;
        int curLevelWidth = 0;
        while(!q.isEmpty()){
            Node cur = q.poll();
            if(cur.left != null){
                q.add(cur.left);
                nextEnd = cur.left;
            }
            if(cur.right != null){
                q.add(cur.right);
                nextEnd = cur.right;
            }
            curLevelWidth++;
            if(cur == curEnd){
                max = Math.max(max, curLevelWidth);
                curLevelWidth = 0;
                curEnd = nextEnd;
            }
        }
        return max;
    }


  

}
```

# 二叉树的序列化和反序列化

- 三序递归:
	- 先序 -- 序列化
		- 怎么遍历的, 就怎么序列化, 注意要将 null 也序列化
	- 先序 -- 反序列化
		- 同顺序反序列化
	- 中序: 不好处理反序列化问题
	- 后序 -- 序列化
		- 序列化一样
	- 后序 -- 反序列化 (左右中)
		- 准备一个 stack, 放进去 (中右左)
		- 到小过程中去弹栈处理.

- 按行序列化和反序列化
	- 序列化
		- 除了要遍历之外, 还要将左右节点不存在的情况的 null 存入
	- 反序列化
		- 准备两个队列, 一个用来遍历, 一个用来获取值生成 Node
		- 如果生成的 Node 不为 null, 就放到遍历队列中依次处理.

```java
package class007;

/**
 * @author Item
 */
public class Code05_SerilizeAndReconstruct {
    public static class Node {
        int value;
        Node left;
        Node right;

        public Node(int v) {
            this.value = v;
        }
    }

    public static Queue<String> preSerialize(Node head) {
        Queue<String> res = new LinkedList<>();
        pres(head, res);
        return res;
    }

    public static void pres(Node head, Queue<String> q) {
        if (head == null) {
            q.add(null);
        } else {
            q.add(String.valueOf(head.value));
            pres(head.left, q);
            pres(head.right, q);
        }
    }

    public static Node buildByPreQue(Queue<String> q) {
        if (q == null || q.size() == 0) {
            return null;
        }
        return preb(q);
    }

    public static Node preb(Queue<String> q) {
        String s = q.poll();
        if (s == null) {
            return null;
        }
        //顺序保持一致
        Node head = new Node(Integer.valueOf(s));
        head.left = preb(q);
        head.right = preb(q);
        return head;
    }

    public static Queue<String> inSerilize(Node head) {
        Queue<String> que = new LinkedList<>();
        if (head == null) {
            return null;
        }
        ins(head, que);
        return que;
    }

    //尽量不要采用中序遍历, 因为不同的二叉树中序遍历得到的结果可能相同
    public static void ins(Node head, Queue<String> que) {
        if (head == null) {
            que.add(null);
        } else {
            ins(head.left, que);
            que.add(String.valueOf(head));
            ins(head.right, que);
        }
    }

    public static Queue<String> posSerialize(Node head) {
        if (head == null) {
            return null;
        }
        Queue<String> que = new LinkedList<>();
        poss(head, que);
        return que;
    }

    public static void poss(Node head, Queue<String> que) {

        if (head == null) {
            que.add(null);
        } else {
            poss(head.left, que);
            poss(head.right, que);
            que.add(String.valueOf(head.value));
        }
    }

    public static Node buildByPosQue(Queue<String> que) {
        if (que == null || que.size() == 0) {
            return null;
        }
        //que中顺序 : 左右中 ; stack中顺序: 中右左
        Stack<String> stack = new Stack<>();
        while (!que.isEmpty()) {
            stack.push(que.poll());
        }
        return posb(stack);
    }

    public static Node posb(Stack<String> stack) {
        String value = stack.pop();
        if (value == null) {
            return null;
        }
        Node head = new Node(Integer.valueOf(value));
        head.right = posb(stack);
        head.left = posb(stack);
        return head;
    }

    public static Queue<String> serializeByLevel(Node head) {
        Queue<String> ans = new LinkedList<>();
        if (head == null) {
            ans.add(null);
        } else {
            ans.add(String.valueOf(head.value));
            Queue<Node> que = new LinkedList<>();
            que.add(head);
            while (!que.isEmpty()) {
                head = que.poll();
                if (head.left != null) {
                    ans.add(String.valueOf(head.left.value));
                    que.add(head.left);
                } else {
                    ans.add(null);
                }
                if (head.right != null) {
                    ans.add(String.valueOf(head.right.value));
                    que.add(head.right);
                } else {
                    ans.add(null);
                }
            }
        }
        return ans;
    }

    public static Node buildTreeByLevelQue(Queue<String> que) {
        if (que == null || que.size() == 0) {
            return null;
        }
        Queue<Node> nodeQue = new LinkedList<>();
        Node head = generateNode(que.poll());
        if (head != null) {
            nodeQue.add(head);
        }
        Node node = null;
        while (!nodeQue.isEmpty()) {
            node = nodeQue.poll();
            node.left = generateNode(que.poll());
            node.right = generateNode(que.poll());
            if (node.left != null) {
                nodeQue.add(node.left);
            }
            if (node.right != null) {
                nodeQue.add(node.right);
            }
        }
        return head;
    }

    public static Node generateNode(String s) {
        if (s == null) {
            return null;
        }

        return new Node(Integer.valueOf(s));
    }
}
```

```java
            return;
        }

        int nodeLen = node.length();
        int lenL = (len - nodeLen) / 2;
        int lenR = len - lenL - nodeLen;
```

# 找到后继点和前驱点 (中序, 带 parent 指针)

- 是否有右子节点:
	- 有 :
		- 找到右节点的最左节点
	- 没有:
		- 往上移动到父节点, 一直找到自己是某个父节点的左孩子.

```java
    public static class Node {
        public int value;
        Node left;
        Node right;
        Node parent;

        public Node(int data) {
            this.value = data;
        }
    }
    public static Node findSucceedNode(Node node) {
        if (node == null) {
            return null;
        }
        if (node.right != null) {
            //有右子树
            return getLeftest(node.right);
        }
        else{
            //没有右子树, 需要往上找到第一个自身是它的左儿子的父节点
            while(node.parent != null){
                if(node == node.parent.left){
                    return node.parent;
                }
                node = node.parent;
            }
            return null;
        }
    }

    public static Node getLeftest(Node node){
        while(node.left != null){
            node = node.left;
        }
        return node;
    }
```

# 最大平衡树

- 平衡树概念: 左边是平衡树, 右边也是平衡树, 左右高度差的绝对值 < 2
- 递归 info 构建:
	- 是不是平衡树 :boolean isBalanced
	- 高度是多少 int height

- 递归过程:
	- if(null){return new Info(true, 0)}
	- 获取左 info 和右 info
	- 判断是否平衡:
		- 左平衡, 右平衡, 且高度差绝对值 < 2
	- 获取高度
		- 左右高度的最大值 + 1

```java
    public static class Node {
        public int value;
        public Node left;
        public Node right;

        public Node(int data) {
            this.value = data;
        }

    }
    public static boolean isBalanced1(Node head) {
        boolean[] ans = new boolean[1];
        ans[0] = true;
        process1(head, ans);
        return ans[0];
    }

    public static int process1(Node head, boolean[] ans) {
        if (!ans[0] || head == null) {
            return -1;
        }
        int leftHeight = process1(head.left, ans);
        int rightHeight = process1(head.right, ans);
        if (Math.abs(leftHeight - rightHeight) > 1) {
            ans[0] = false;
        }
        return Math.max(leftHeight, rightHeight) + 1;
    }


    public static boolean isBalanced(Node head){
        return process(head).isBalanced;
    }
    public static class Info{
        boolean isBalanced;
        int height;

        public Info(boolean isB, int h){
            isBalanced = isB;
            height = h;
        }
    }

    public static Info process(Node node){
        if(node == null){
            return new Info(true, 0);
        }
        Info leftInfo = process(node.left);
        Info rightInfo = process(node.right);
        int height = Math.max(leftInfo.height, rightInfo.height) + 1;
        if(leftInfo.isBalanced && rightInfo.isBalanced && (Math.abs(leftInfo.height - rightInfo.height)) < 2){
            return new Info(true, height);
        }
        return new Info(false, height);
    }
```

# 找到二叉树的最远距离

- 区分依据: 是否包含自身
	- 包含自身, 左高 + 右高 + 1
	- 不包含自身, max(左最远, 右最远)
- 递归 info 构建
	- 最远距离
	- 高度
- 递归过程 :
	- 为空 : (0,0)
	- 最远 = max(左最远, 右最远, 左高 + 右高 + 1)
	- 高度 = max(左高, 右高) + 1;

```java
    public static class Info {
        int maxDistance;
        int height;

        public Info(int maxDistance, int height) {
            this.maxDistance = maxDistance;
            this.height = height;
        }
    }

    public static Info process(Node node) {
        if (node == null) {
            return new Info(0, 0);
        }

        Info leftInfo = process(node.left);
        Info rightInfo = process(node.right);

        int height = Math.max(leftInfo.height ,rightInfo.height) + 1;
        int maxDistance = Math.max(Math.max(leftInfo.maxDistance,rightInfo.maxDistance),
                leftInfo.height + rightInfo.height + 1);
        return new Info(maxDistance,height);
    }

    public static int getMaxDistance(Node node){
        return process(node).maxDistance;
    }
```

# 找到最大子搜索树

- 这个最大子搜索树包不包括自己 ?
	- 不包括, 左最大和右最大比较
	- 包括 : 条件
		- 左右都是
		- 左最大值 < x.value
		- 右最小值 > x.value
- 构建 info
	- int min, max
	- boolean isBST
	- int subBSTSize(在 isSBT = True) 的时候, 就是

- 递归过程 :
	- if(null)return null
	- 先考虑 isSBT = false 的情况
	- int min, max = x.value
		- 如果有 leftInfo 和 rightInfo, 进行比较更新
	- maxBSTSize
		- 如果有 leftInfo 和 rightInfo, 进行比较更新
	- 如果:
		- 左右 info 都不为空, 且都是搜索树
		- 左右 info 都不为空, 且左最大值 < x.value < 右最小值
		- 置 isSBT = true; 置 maxSBTSize = 左 size + 右 size + 1

```java
    public static class Info {
        int min;
        int max;
        boolean isSBT;
        int maxSubBSTSize;

        public Info(int min, int max, boolean isSBT, int maxSubBSTSize) {
            this.min = min;
            this.max = max;
            this.isSBT = isSBT;
            this.maxSubBSTSize = maxSubBSTSize;
        }
    }

    public static Info process(Node node) {
        if (node == null) {
            return null;
        }
        Info leftInfo = process(node.left);
        Info rightInfo = process(node.right);

        int min = node.value;
        int max = node.value;

        if (leftInfo != null) {
            min = Math.min(leftInfo.min, min);
            max = Math.max(leftInfo.max, max);
        }

        if (rightInfo != null) {
            min = Math.min(rightInfo.min, min);
            max = Math.max(rightInfo.max, max);
        }
        //情况1
        int maxSubBSTSize = 1;
        if (leftInfo != null) {
            maxSubBSTSize = leftInfo.maxSubBSTSize;
        }
        if (rightInfo != null) {
            maxSubBSTSize = Math.max(rightInfo.maxSubBSTSize, maxSubBSTSize);
        }

        boolean isBST = false;
        if (    //左边是不是搜索树?右边是不是搜索树?
                (leftInfo != null ? leftInfo.isSBT : true)
                &&
                (leftInfo != null ? leftInfo.isSBT : true)
                && //左边的最大值比node小
                (leftInfo != null ? leftInfo.max < node.value : true)
                && //右边的最小值比node大
                (rightInfo != null ? rightInfo.min > node.value : true)
        ) {
            isBST = true;
            maxSubBSTSize = (leftInfo != null ? leftInfo.maxSubBSTSize : 0)
                    + (rightInfo != null ? rightInfo.maxSubBSTSize : 0) + 1;
        }

        return new Info(min, max, isBST, maxSubBSTSize);
    }

    public static int findMaxSubBSTSize(Node node){
        return process(node).maxSubBSTSize;
    }
```

# 找出最大快乐值

- 递归判断:
	- 当前节点参不参加:
		- 参加: sum(子节点不参加的最大快乐的总和)
		- 不参加 : sum(max(子节点参加, 子节点不参加) 的总和)
- info 设置
	- 参加的最大 comeHappy
	- 不参加的最大 noComeHappy

```java
    public static class Employee{
        public int happy;
        public List<Employee> nexts;

        public Employee(int happy) {
            this.happy = happy;
            nexts = new ArrayList<Employee>();
        }
    }

    public static int getMaxHappy(Employee boss){
        if(boss == null){
            return 0;
        }
        Info info = process(boss);
        return Math.max(info.comeHappy, info.noComeHappy);
    }

    public static class Info{
        int comeHappy;
        int noComeHappy;

        public Info(int comeHappy, int noComeHappy) {
            this.comeHappy = comeHappy;
            this.noComeHappy = noComeHappy;
        }
    }

	public static Info process(Employee x){
        if(x == null){
            return new Info(0,0);
        }
        
        int comeHappy = x.happy;
        int noComeHappy = 0;
        for(Employee e : x.nexts) {
            Info info = process(e);
            comeHappy += info.noComeHappy;
            noComeHappy += Math.max(info.comeHappy, info.noComeHappy);
        }

        return new Info(comeHappy,noComeHappy);
    }
```

```java
    public static void morris(Node head) {
        if (head == null) {
            return;
        }
        Node cur = head;
        Node mostRight = null;
        while (cur != null) {
            mostRight = cur.left;
            if (mostRight != null) {
                while (mostRight.right != null && mostRight.right != cur) {
                    mostRight = mostRight.right;
                }
                if (mostRight.right == null) {
                    mostRight.right = cur;
                    cur = cur.left;
                    continue;
                } else {//最右指向当前
                    mostRight.right = null;
                }
            }
            cur = cur.right;
        }
    }

        Node next = null;

            next = from.right;
            from.right = pre;
            pre = from;
            from = next;
        }
        return pre;
    }
```
